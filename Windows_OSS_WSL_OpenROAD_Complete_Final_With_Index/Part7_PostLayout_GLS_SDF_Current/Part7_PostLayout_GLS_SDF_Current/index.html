3. Why Functional PASS ≠ Timing PASS

Functional GLS proves the mapped gate network computes the expected registered threshold function. SDF timing GLS additionally requires the simulator to match SDF timing arcs/interconnects to timing-capable cell models and actually apply those delays. Therefore correct output values alone are insufficient evidence of successful SDF back-annotation.

4. SKY130 / ModelSim compatibility work

ModelSim 10.5b initially rejected the SKY130 behavioral models under default_nettype none. A compatibility copy explicitly declared old-style ports as nets (for example output wire Y; and input wire A;). After this compatibility adjustment, all 12 required cell types and the DFRTP UDP compiled successfully. The original Linux SKY130 repository was not the target of this compatibility edit.
