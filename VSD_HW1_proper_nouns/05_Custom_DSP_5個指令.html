05｜Custom DSP：5 個指令

DOTP4 · SADD8 · SSUB8 · ABS · CLIP8，以及 packed lanes、two's-complement、saturation、clipping、sign extension 等相關專有名詞。每個條目至少 2 個例子。
HW1 重點：五條 Custom DSP instructions 的 opcode 都是 0001011；DOTP4/SADD8/SSUB8 的 byte elements 依 signed two's-complement 解讀；SADD8/SSUB8 是 per-lane saturation；ABS/CLIP8 為 unary operations，rs2 field 必須是 00000。

01DOTP44-way Dot Product｜四組 8-bit 點積⌄
Custom DSP 指令

HW1 規格／依據

Custom DSP table：funct7=0000000、[24:20]/rs2=rs2、funct3=000、opcode=0001011；operation：Σ signed(rs1 lane i) × signed(rs2 lane i)。

詳細說明

把兩個 32-bit operands 各切成四個 8-bit elements。每個 byte 都依 signed two's-complement 解讀，再將四組乘積相加。

例子（至少 2 個）

例 1

rs1=0x01010101、rs2=0x01010101 → 1×1 共四組，結果=4。

例 2

rs1=0xFFFFFFFF、rs2=0x01010101；0xFF=-1，因此結果=(-1)×1×4=-4。

例 3

四 lanes 為 [1,2,3,4] 與 [5,6,7,8] → 5+12+21+32=70。

02SADD8Saturating Add 8-bit｜四路 8-bit 有號飽和加法⌄
Custom DSP 指令

HW1 規格／依據

Custom DSP table：funct7=0000000、[24:20]/rs2=rs2、funct3=001、opcode=0001011；operation：per-lane signed add, saturated to [-128,127]。

詳細說明

四個 8-bit lanes 各自做 signed addition，再各自限制在 [-128,127]。PDF 強調 saturation 是 per lane independently。

例子（至少 2 個）

例 1

100+50=150 → 超過 127，因此該 lane=127。

例 2

20+30=50 → 在範圍內，輸出 50。

例 3

-100+(-50)=-150 → 低於 -128，因此該 lane=-128。

03SSUB8Saturating Subtract 8-bit｜四路 8-bit 有號飽和減法⌄
Custom DSP 指令

HW1 規格／依據

Custom DSP table：funct7=0000000、[24:20]/rs2=rs2、funct3=010、opcode=0001011；operation：per-lane signed subtract, saturated to [-128,127]。

詳細說明

四個 8-bit lanes 分別計算 rs1_lane-rs2_lane，之後各自進行 signed 8-bit saturation。

例子（至少 2 個）

例 1

80-30=50 → 輸出 50。

例 2

100-(-50)=150 → 飽和為 127。

例 3

-100-50=-150 → 飽和為 -128。

04ABSAbsolute Value｜32-bit 有號絕對值⌄
Custom DSP 指令

HW1 規格／依據

Custom DSP table：funct7=0000000、[24:20]/rs2=00000、funct3=011、opcode=0001011；operation：abs(signed(rs1)); 0x80000000 → 0x7FFFFFFF。

詳細說明

對 signed 32-bit rs1 取絕對值。PDF 特別規定最小 signed 32-bit 值 0x80000000 的結果要飽和為 0x7FFFFFFF。ABS 是 unary operation，因此 rs2 field=00000。

例子（至少 2 個）

例 1

rs1=-25 → result=25。

例 2

rs1=123 → result=123。

例 3

rs1=0x80000000 → HW1 指定 result=0x7FFFFFFF。

05CLIP8Clip to Signed 8-bit Range｜限制到 signed 8-bit 範圍⌄
Custom DSP 指令

HW1 規格／依據

Custom DSP table：funct7=0000000、[24:20]/rs2=00000、funct3=100、opcode=0001011；operation：clamp signed(rs1) to [-128,127], then sign-extend。

詳細說明

把 signed 32-bit rs1 clamp 到 [-128,127]，最後以 32-bit sign-extended result 輸出。CLIP8 也是 unary operation，因此 rs2 field=00000。

例子（至少 2 個）

例 1

rs1=200 → 127 → 0x0000007F。

例 2

rs1=-200 → -128 → 0xFFFFFF80。

例 3

rs1=-20 → 保持 -20 → 0xFFFFFFEC。
