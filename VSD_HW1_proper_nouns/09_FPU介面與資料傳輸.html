09｜FPU 介面與資料傳輸

依 VSD HW1 的 FPU I/O 與 Data Transfer 頁面整理：clk、rst、enable、ai、bi、instruction、co、valid，以及 reset → feed data → wait valid → compare golden → next cycle 的完整資料交換流程。
規格界線：PDF 明確給出 FPU ports、instruction encoding 與 Data Transfer 順序；但沒有在這些頁面明確指定固定 N-cycle latency、ready signal 或標準 ready/valid protocol。因此本頁不自行加入這些未寫明的介面規格，精確 cycle 行為以老師提供的 FPU_tb.sv 為準。

01FPU InterfaceFPU 介面⌄
核心介面名詞Floating-Point Unit Interface

HW1 PDF 中的依據

HW1 PDF 的 FPU I/O table 定義 clk、rst、enable、ai、bi、instruction、co、valid。

詳細說明

Interface 是 FPU 與 testbench／外部控制邏輯交換資料與控制資訊的邊界。本作業的輸入包含 clock、reset、enable、兩個 32-bit operands 與 2-bit instruction；輸出則包含 32-bit result 與 valid。

例子（至少 2 個）

例 1

testbench 透過 ai、bi 把兩個 32-bit floating-point operands 送進 FPU。

例 2

FPU 完成後透過 co 輸出結果，並以 valid 告知結果可被檢查。

04Clock Cycle時脈週期⌄
時序名詞Clock Cycle

HW1 PDF 中的依據

PDF Data Transfer 頁使用 next cycle 描述下一筆輸入資料的送入時機。

詳細說明

一個 clock cycle 是相鄰 clock 邊緣之間的一個週期。此處只依 PDF 說明資料傳輸順序，不自行假定 FPU 固定 latency 是幾個 cycles。

例子（至少 2 個）

例 1

某筆 operation 完成、valid high 後，下一 cycle 再 feed new data。

例 2

若 valid 尚未 high，就依 PDF 流程繼續等待，而不是自行假定固定第 N cycle 完成。

詳細說明

HW1 PDF 中的依據

PDF FPU I/O：bi 為 32-bit input。

詳細說明

bi 是第二個 floating-point operand。SUB 時它是被減數運算式中的 B；比較時則與 ai 一起送入 comparator。

例子（至少 2 個）

例 1

ADD：功能上計算 ai + bi。

例 2

10instructionFPU 指令控制輸入⌄

HW1 PDF 中的依據

PDF FPU I/O：instruction 為 2 bits；0=min、1=max、2=add、3=sub。

詳細說明

instruction 告訴 FPU 本筆 transaction 要執行哪一種 operation，並對應 FPU Comparator 或 FPU Adder 路徑。

例子（至少 2 個）

例 2

詳細說明
