二、第 3 頁：為什麼 VLSI 要使用 Linux？

教材列出的 Linux 優點有四項：

  • The system has high stability.
  • Supports multiple tools and multiple users.
  • Convenient for managing groups.
  • A commonly used operation system in the industry.

缺點則是：

  • The graphical interface is not user-friendly enough.
  • Requires time to learn command usage.

三、第 5 頁：ls —— 看目前有哪些東西

ls
ls -a
ls -l

ls 顯示檔案與目錄；ls -a 連隱藏檔也顯示；ls -l 顯示更完整的資訊，例如 permission、owner、size、last modified time。

ls

$ ls
Lab1  test.v  tb.v

ls -a

Linux 隱藏檔通常以 . 開頭，例如：

.bashrc
.profile

ls -l

-rw-r--r-- 1 user group 2048 Sep 14 test.v
-rw-r--r--    permission
user          owner
group         group
2048          size
Sep 14        modification time
test.v        filename

十、第 11 頁：直接指定檔案開啟 gedit

gedit test.txt &

表示用 gedit 開啟已存在的 test.txt。

gedit 123.txt &

表示用 gedit 開啟一個名為 123.txt 的新檔案。

同樣概念可延伸成：

gedit top.v &
gedit tb_top.v &

十一、第 12 頁：more —— 在 Terminal 看檔案內容

more test.txt

功能是直接在 terminal 顯示檔案內容。

指令用途
gedit test.txt &圖形介面打開／編輯
more test.txtTerminal 查看

      ↓ cp

十三、第 14 頁：mv —— Move，而且也可以 Rename

mv test.txt hw1.txt

把 test.txt 改成 hw1.txt。

mv hw1.txt ../Lab2

把 hw1.txt 移到 Lab2 directory。

mv Lab2 Lab3

把 directory Lab2 改成 Lab3。

mv source destination

destination 是另一個 filename
→ rename

destination 是 directory
→ move

十四、cp 和 mv 最大區別

cp = Copy
原檔案還在
+
產生複製品
mv = Move
原位置的檔案不在
→ 跑到新位置
cp top.v backup.v

結果：

top.v
backup.v
mv top.v backup.v

結果只有：

backup.v

十五、第 15 頁：rm —— 刪除

rm homework.txt

刪除 homework.txt。

rm -r Lab3

刪除 Lab3 directory。

這是整份教材裡最需要小心的指令之一。 rm -r 會遞迴刪除整個目錄及其內容。

十六、第 16 頁：rmdir

rmdir Lab4

rm file
   ↓
刪除檔案

rmdir empty_directory

rm -r directory

十七、第 17 頁：tar

tar -cvf Lab1.tar Lab1

教材描述為把 Lab1 壓成 Lab1.tar。

tar -xvf Lab1.tar

教材描述為把 Lab1.tar 解回原目錄。

-c : create file
-v : show the info.
-f : following is the file name
-x : decompress file
tar -cvf Lab1.tar Lab1
     │││
     ││└─ f → 後面指定 archive filename
     │└── v → 顯示處理過程
     └─── c → 建立 archive
tar -xvf Lab1.tar
     │││
     ││└─ filename
     │└── verbose
     └─── extract
