00-6｜IEEE-754 Single Precision：FPU 前一定要懂的浮點表示法

這一章以 HW1 講義的 IEEE-754/FPU 部分為主要依據：Single Precision 為 32 bits，由 1-bit Sign + 8-bit Exponent + 23-bit Fraction 組成；講義接著用 Mantissa、GRS、Round-to-even 與特殊值分類銜接 FPU ADD/SUB。以下先把「一個 32-bit hex 到底代表什麼浮點數」徹底拆開。

二、Normal Number：為什麼公式是 (-1)^S × (1.F) × 2^(E-127)？

Value = (-1)S × (1.F) × 2E-127
部分意義
(-1)^SS=0 為正；S=1 為負。
1.FNormal number 的 leading 1 不存進 fraction，稱 hidden/implicit 1。
E-1278-bit exponent 採 bias=127；stored E 不是直接的真實次方。

例：2.5 = 0x40200000

0x40200000
S = 0
E = 10000000₂ = 128
F = 01000000000000000000000₂

1.F = 1.01₂ = 1.25
真實 exponent = 128 - 127 = 1

Value = (+1) × 1.25 × 2¹ = 2.5

這裡也提醒：課堂投影片範例欄位與十六進位標示若出現不一致，實作時應以 32-bit S/E/F 位元拆解與官方測資為準。本頁用一致的 0x40200000 = 2.5 示範位元計算。

五、為什麼有 +0 和 -0？

+0 = 0x00000000
-0 = 0x80000000

兩者 exponent=0、fraction=0，只有 sign 不同。這對 HW1 很重要，因為講義在 FPU ADD/SUB special cases 明確寫到 0+0 的結果可能是 +0 或 -0，取決於 signs。因此不能看到「數值都是 0」就把 sign bit 永遠清成 0。

六、Subnormal：為什麼不能補 hidden 1？

Normal 使用 1.F；但 Subnormal 的 exponent field 是 0、fraction 非 0，它的有效 significand 是 0.F。所以硬體 unpack 時不能寫成「所有非 Zero 都補 1」。

E=0?→F=0 → Zero；F≠0 → Subnormal

講義這幾頁沒有進一步完整指定所有 subnormal arithmetic/underflow 的實作細節，因此最終 FPU 行為仍應以正式作業規格與官方 patterns 驗證；但分類時絕對不能把它當 Zero。

八、Mantissa 與 GRS：IEEE-754 如何接到 FPU 加減法？

Unpack S/E/F→比較 Ea/Eb→較小 Mantissa 右移 ΔE→保留 G/R/S→Add/Sub→Normalize→Round→Pack
Bit講義定義
G — GuardMantissa 被 shift 出去的第一個 bit。
R — Round第二個被 shift 出去的 bit。
S — StickyR 後面任何一個被 shift 掉的 bit 是 1，Sticky 就設成 1。

GRS 的目的不是「多存三個 fraction bits」，而是保留被 alignment 丟掉的資訊，讓最後 rounding 能做正確決策。

九、Round-to-Even：GRS=100 為什麼還要看 LSB？

GRS保留結果的 LSBAction原因
0xxXDiscard未到 half-way
101 / 110 / 111XRound up超過 half-way
1001Round up剛好 tie，往偶數方向讓 LSB 變 0
1000Discard剛好 tie，現在已是 even
常用判斷式：round_up = G & (R | S | LSB)

這就是表格裡「GRS=100 為什麼還要看 LSB？」的答案：因為 100 表示 exactly halfway，Round-to-nearest-even 必須選最後保留 bit 為偶數（LSB=0）的那一邊。

十、從 IEEE-754 到 HW1 FPU 的完整流程

ai / bi→Unpack S/E/F→Classify→Special Case?No →Effective Sign→ΔE Align→Mantissa Add/Sub→Normalize→GRS RNE→Repack 32-bit→co + valid

講義的 ADD/SUB 流程正是：較小 exponent 的 mantissa 右移 ΔE=|Ea-Eb| → 依 signs/instruction 做 mantissa add/sub → carry 或 cancellation normalization → GRS rounding → repack。
