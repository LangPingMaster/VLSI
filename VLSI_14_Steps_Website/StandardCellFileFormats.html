1. 為什麼一顆 Standard Cell 要有很多檔案？

同一顆 standard cell，例如一顆 inverter，對不同 EDA tool 來說需要完全不同的資訊： Synthesis 想知道 timing / power，P&R 想知道尺寸與 pin 位置，simulator 想知道邏輯功能， LVS 想知道 transistor-level connectivity，而 fabrication 最後需要完整 mask layout。

同一顆 Cell例如 INV_X1
→
Timing View.lib / .db
Physical Abstract.lef
Functional View.v / .slib
Full Layout.gds
Circuit View.cdl / .spi
核心觀念：這些檔案不是五顆不同的 cell，而是同一顆 cell 的不同 view。

2. .lib / .db：Timing & Power View

課程明確指出 .lib / .db 是 Timing & Power View， 主要包含 propagation delay、setup/hold times、dynamic power、leakage power，以及 NLDM / CCS 等模型。

2.1 .lib 是什麼？

.lib 通常是文字格式的 Liberty library。 它會描述 cell、pin、function、timing arc、capacitance、transition、power 等資訊。

2.2 .db 是什麼？

在常見 Synopsys flow 中，.db 可理解為由 Liberty library 編譯而成、供工具快速讀取的 binary database。

上面對 .db 的 binary database 說明屬於實務補充；課程投影片直接把 .lib/.db 合併列為 Timing & Power View。

2.3 示意 .lib 內容

cell (INV_X1) {
    area : 1.20;

    pin (A) {
        direction : input;
        capacitance : 0.002;
    }

    pin (ZN) {
        direction : output;
        function : "!A";

        timing() {
            related_pin : "A";
            cell_rise(...);
            cell_fall(...);
            rise_transition(...);
            fall_transition(...);
        }
    }
}

2.4 Synthesis 為什麼需要它？

因為 synthesis 不只是要知道「INV_X1 是反相器」，還需要比較不同 cell 的 area、delay、power， 才能決定該選 X1、X2、X4 或其他等價 cell。

2.5 STA 為什麼需要它？

STA 要沿 timing paths 累加 cell delay，並檢查 setup / hold。 因此 timing arcs、input slew、output load 等模型都非常重要。

3. .lef：Library Exchange Format

課程指出 LEF 是 abstract geometry，包含： cell boundary（bounding box）、obstruction layers、pin locations，主要給 P&R 使用。

LEF 不是完整 layout。它是「給 place-and-route 看得懂的抽象版圖」。

3.1 為什麼 P&R 不需要完整 transistor geometry？

Placement 階段最重要的是知道 cell 多寬、多高；routing 最重要的是知道 pin 在哪裡、 哪些區域不能走線。這些資訊 LEF 就足夠。

3.2 示意 LEF

MACRO INV_X1
  CLASS CORE ;
  ORIGIN 0 0 ;
  SIZE 1.2 BY 2.8 ;

  PIN A
    DIRECTION INPUT ;
    PORT
      LAYER metal1 ;
      RECT 0.10 1.10 0.20 1.30 ;
    END
  END A

  PIN ZN
    DIRECTION OUTPUT ;
    PORT
      LAYER metal1 ;
      RECT 1.00 1.10 1.10 1.30 ;
    END
  END ZN
END INV_X1

3.3 LEF 中常見資訊

資訊用途
Cell SizePlacement 知道 cell 占多大
Pin LocationRouter 知道從哪裡接線
Routing LayerRouter 知道 pin 在哪一層金屬
Obstruction避免 routing 穿過不可用區域

4. .v / .slib：Functional View

課程將 .v / .slib 定義為 Functional View， 主要是 gate-level Verilog netlist / behavioral description，用於 functional simulation。

4.1 Inverter functional model

module INV_X1 (
    input  A,
    output ZN
);
    assign ZN = ~A;
endmodule

4.2 NAND functional model

module NAND2_X1 (
    input A1,
    input A2,
    output ZN
);
    assign ZN = ~(A1 & A2);
endmodule

4.3 DFF functional model

module DFF_X1 (
    input D,
    input CK,
    output reg Q
);
    always @(posedge CK)
        Q <= D;
endmodule

4.4 Gate-Level Simulation

// synthesized netlist
INV_X1  U1 (.A(a), .ZN(n1));
NAND2_X1 U2 (.A1(n1), .A2(b), .ZN(y));

Simulator 需要知道 INV_X1、NAND2_X1 是什麼，因此會載入 library 的 functional Verilog model。

5. .gds / .gdsii：Full Physical View

課程指出 GDS / GDSII 包含完整 mask layout data， 包括 diffusion、poly、metal 等所有實體層資訊，可用於 fabrication。

Cell Layout
→
GDS/GDSII完整 polygons / layers
→
Chip Final Layout
→
Fabrication

5.1 GDS 與 LEF 的差別

項目LEFGDS
細節程度抽象完整
Cell boundary有有
Pin location有有完整 geometry
Diffusion / Poly通常不需完整細節完整
主要用途P&RFinal layout / fabrication
不要把 LEF 當 GDS：LEF 是抽象 physical view；GDS 才是完整 mask layout view。

6. .cdl / .spi：Circuit View

課程指出 .cdl / .spi 是 Circuit View， 包含 SPICE transistor-level netlist，用於 LVS 與 SPICE simulations。

6.1 Inverter SPICE 示意

.SUBCKT INV_X1 A ZN VDD VSS

MP1 ZN A VDD VDD PMOS W=... L=...
MN1 ZN A VSS VSS NMOS W=... L=...

.ENDS INV_X1

6.2 為什麼 LVS 要用 Circuit View？

LVS = Layout Versus Schematic。工具會從 layout extract 出 transistor/connectivity， 再與 schematic/circuit netlist 比對，因此需要 transistor-level circuit reference。

6.3 SPICE Simulation

若要量真實 transistor-level delay、slew、power，就需要 circuit model，而不是只看 Verilog Boolean function。

7. Cell Characterization 與檔案格式的關係

課程定義 Cell Characterization 為： 對 transistor-level cell 在不同 PVT corners 下執行大量 SPICE simulations， 量測 delay、slew rate、power。

.cdl / .spiTransistor Netlist
+
PVT Conditions
→
SPICE Characterization
→
Timing / Power Tables
→
.lib / .db
這個關係非常重要：
.cdl/.spi 是 cell 的 transistor-level circuit；
characterization 從這個 circuit 量出 timing/power；
結果再被整理進 .lib/.db。

8. NLDM：Timing Table 為什麼是二維？

課程指出 NLDM 的 delay 以 2D lookup table 儲存， 索引是： Input Slew (Transition Time) 與 Output Load Capacitance。

Input Slew ↓ / Load →Small LoadMedium LoadLarge Load
Fast Slew小 delay較大更大
Medium Slew較大更大更大
Slow Slew更大更大通常最差

上表數值關係是概念示意，不是課程提供的實際 cell 數據；課程明確支持的是「NLDM 為 2D lookup table，以 input slew 與 output load capacitance 為索引」。

示意 Liberty table

cell_rise(delay_template) {
    index_1("0.01, 0.05, 0.10");  // input slew
    index_2("0.001, 0.01, 0.05"); // output load

    values(
      "0.02, 0.03, 0.05",
      "0.03, 0.04, 0.07",
      "0.05, 0.07, 0.10"
    );
}

9.1 Synthesis

主要需要 timing/power library，依 cell delay、area、power 進行 technology mapping。

9.2 Gate-Level Simulation

需要 synthesized gate-level netlist 與 standard-cell functional Verilog model。

9.3 Place & Route

需要 LEF 的 cell size / pin / obstruction，以及 timing library 做 timing-driven optimization。

9.4 LVS

需要 extracted layout circuit 與 CDL/SPICE reference circuit 做比對。

9.5 Final Tape-out

最後使用完整 GDS/GDSII physical layout data。

10. 大量檔案例子：同一顆 INV_X1 看五種 View

例 1：Functional Verilog

    assign ZN = ~A;
endmodule

例 2：Liberty Function

cell (INV_X1) {
    area : 1.2;
    pin(A)  { direction : input; }
    pin(ZN) {
        direction : output;
        function : "!A";
    }
}

例 3：LEF Geometry

  PIN A
    DIRECTION INPUT ;
  END A
  PIN ZN

例 4：SPICE Circuit

.SUBCKT INV_X1 A ZN VDD VSS
MP1 ZN A VDD VDD PMOS
MN1 ZN A VSS VSS NMOS
.ENDS INV_X1

例 5：GDS View

GDS 不適合用簡單文字直接呈現；概念上會包含 INV_X1 的 diffusion、poly、contact、metal polygons 等完整 layout geometry。

例 6：NAND2_X1 的 Functional View

module NAND2_X1(
    input A1,
    input A2,
    output ZN
);
    assign ZN = ~(A1 & A2);
endmodule

例 7：NAND2_X1 的 Circuit View

.SUBCKT NAND2_X1 A1 A2 ZN VDD VSS
* PMOS network
MP1 ZN A1 VDD VDD PMOS
MP2 ZN A2 VDD VDD PMOS

* NMOS network
MN1 ZN A1 n1  VSS NMOS
MN2 n1 A2 VSS VSS NMOS
.ENDS NAND2_X1

例 8：DFF 的 Functional View

module DFF_X1(
    input D,
    input CK,
    output reg Q
);
    always @(posedge CK)
        Q <= D;
endmodule

例 9：DFF 在 .lib 裡的重要 timing

// Conceptual entries
setup_rising(...)
hold_rising(...)
rising_edge(...)
cell_rise(...)
cell_fall(...)

上述 keyword 片段用來幫助理解 sequential cell timing view；課程只明確指出 .lib/.db 會包含 setup/hold、propagation delay、power 等資訊，並未在這頁逐一列出完整 Liberty syntax。

例 10：P&R 只讀 LEF 可以做什麼？

知道 DFF 多寬、CK/D/Q pins 在哪裡、哪些區域可以進線，進而完成 placement 與 routing。

例 11：為什麼 Gate-Level Simulation 不需要 GDS？

Functional simulation 只關心 cell 的 logic behavior，因此載入 .v/.slib 即可，不需要完整 diffusion/poly geometry。

例 12：為什麼 LVS 不只看 Verilog？

LVS 比較 transistor-level connectivity，所以需要 circuit view，例如 .cdl/.spi，而不是只有 Boolean functional model。

例 13：為什麼 STA 不讀 GDS 當 timing library？

STA 需要的是 characterized delay/setup/hold/power tables，因此使用 .lib/.db；完整 polygon layout 不是 timing lookup table。

例 14：一個 library corner 的概念

slow_process / low_voltage / high_temperature
fast_process / high_voltage / low_temperature

這是 PVT corner 的概念性寫法；實際 corner 名稱由 library provider 定義。

12. 常見誤解與考試重點

誤解 1：.lib 就是 Verilog library

錯。.lib 主要是 timing/power characterization，不是 functional Verilog model。

誤解 2：LEF = GDS

錯。LEF 是 abstract geometry；GDS/GDSII 是 full physical layout。

誤解 3：.v 是拿去 fabrication

錯。.v/.slib 是 functional view，主要用於 gate-level functional simulation。

誤解 4：CDL 是 timing table

錯。CDL/SPI 是 transistor-level circuit netlist；timing/power tables 在 .lib/.db。

誤解 5：Cell delay 可以只存一個數字

錯。課程介紹 NLDM，delay 依 input slew 與 output load capacitance 查 2D table。

誤解 6：Characterization 與 SPICE 無關

錯。課程明確說 characterization 是跨 PVT corners 執行大量 transistor-level SPICE simulations。

13. 自我測驗

Q1：Synthesis / STA 最重要的 standard-cell view 是哪個？

.lib/.db，因為包含 timing / power / setup / hold 等資訊。

Q2：P&R 用什麼格式看 cell boundary 與 pin location？

.lef。

Q3：Gate-level functional simulation 需要哪個 view？

.v/.slib functional model。

Q4：完整 mask layout 是哪個格式？

.gds/.gdsii。

Q5：LVS / SPICE 使用哪個 circuit view？

.cdl/.spi。

Q6：NLDM 的兩個主要 index 是什麼？

Input slew（transition time）與 output load capacitance。
