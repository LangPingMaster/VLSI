1. Continuous Assignment 到底是什麼？

在課程投影片中，Continuous Assignment 被介紹成一種描述 combinational logic 的方便方式：由 operands 與 operators 組成運算式， 並把結果持續驅動到 net。

輸入訊號a, b, sel...
→
expression例如 a & b
→
assign
→
wire / net輸出
一句話：
assign 表示「右邊只要有任何輸入改變，左邊的 net 就立即依照這個運算式重新計算」。

2. 基本語法

assign target_net = expression;

例如：

wire out;
assign out = a & b;
部分意義
assignContinuous assignment 關鍵字
out被驅動的 net
a & b右側 expression
;敘述結束
在傳統 Verilog 中，continuous assignment 的左值通常是 wire / net， 而不是 procedural reg。

3. 為什麼叫「Continuous（連續）」Assignment？

它不是「只執行一次」。而是建立一條持續存在的硬體規則： 

assign y = a & b;

概念上：

a 或 b 改變
→
重新計算 a & b
→
更新 y

因此它非常符合真實組合邏輯的行為：AND gate 的輸入一變，輸出也跟著改變。

課程投影片將 continuous assignment 描述為： 在 target variable 與 Boolean expression 之間建立 event-scheduling rule， 並隱藏 module 內部實際 gate 結構。

4. Continuous Assignment 與 wire / net 的關係

4.1 最典型寫法

wire out;
assign out = a & b;

4.2 宣告同時賦值

wire [7:0] c = a + b;

課程投影片特別提到，這種寫法可以在 wire 宣告時就附上 continuous assignment。

4.3 多個 continuous assignments

wire p, q, y;

assign p = a & b;
assign q = c | d;
assign y = p ^ q;

每一條 assign 都可以看成獨立存在的 combinational hardware。 不是從上到下依序執行。

7. Conditional Operator ?:

課程投影片指出，conditional operator 的典型形式為： 

condition ? true_expression : false_expression

它很像 software 的 if-then-else，但在硬體裡常對應到 multiplexer。

7.1 2-to-1 MUX

assign y = sel ? x_in1 : x_in2;

7.2 ALU Operation Select

assign result = (op == ADD) ? (a + b) : (a - b);

7.3 Nested Conditional

assign z = ({s1,s0} == 2'b00) ? IA :
           ({s1,s0} == 2'b01) ? IB :
           ({s1,s0} == 2'b10) ? IC :
           ({s1,s0} == 2'b11) ? ID :
                                1'bx;

9. Continuous Assignment 中的 Delay

課程投影片也展示了 delay 寫法：

wire #10 inv = ~in;

這表示模擬時加入 delay。它常用於模擬 timing behavior。

重要：這類 delay 語法主要是 simulation behavior。 在一般 RTL synthesis flow 中，不應把它當成「要求硬體真的產生 10 個時間單位延遲」的方式。

10. assign 與 always @(*) 有什麼差別？

Continuous Assignment

wire y;
assign y = a & b;

簡單、直接，非常適合單一 expression。

Procedural Combinational

reg y;
always @(*) begin
    y = a & b;
end

適合較複雜的 if / case / 多步驟組合邏輯。

若兩者描述的 Boolean function 相同，synthesis 後可能得到相同或等價的硬體。

11.1 MUX

assign y = sel ? a : b;

通常會被推導成 multiplexer。

11.2 Adder

assign y = a + b;

通常會被推導成 combinational adder logic。

11.3 Comparator

assign eq = (a == b);

會形成 equality comparison logic。

11.4 Boolean Logic Optimization

assign y = (a & b) | (a & c);

Synthesis 工具可能把它最佳化成等價形式 a & (b | c)。

12. 常見錯誤與考試重點

錯誤 1：造成 combinational loop

課程投影片直接提醒要避免 logic loop，例如：

assign a = b + a;
右側又依賴自己，可能形成 combinational feedback loop。 除非是非常特殊且刻意的電路，不應在一般 RTL 中這樣寫。

錯誤 2：把 assign 當成 sequential execution

assign a = x & y;
assign b = a | z;

這不是「先執行第一行、再執行第二行」。 兩個 continuous assignments 同時存在，像兩組硬體同時工作。

錯誤 3：左邊使用 procedural reg

// 傳統 Verilog 中不建議/不合法的典型概念
reg y;
assign y = a & b;

continuous assignment 的 target 應該是 net 型別。

錯誤 4：混淆 bitwise 與 logical operator

// bitwise
assign y1 = a & b;

// logical
assign y2 = a && b;

對單 bit 可能看起來相似，但多位元資料時語意不同。

錯誤 5：width 不匹配

wire [3:0] y;
wire [7:0] a;

assign y = a;

高位可能被截掉。寫 RTL 時要特別留意 vector width。

13. 自我測驗

Q1：為什麼 assign 適合描述 combinational logic？

因為任何 RHS 輸入改變時，輸出都會依據 expression 重新計算，符合組合邏輯持續反應的特性。

Q2：assign y = sel ? a : b; 通常對應什麼硬體？

2-to-1 multiplexer。

Q3：assign y = a + b; 是不是軟體加法？

不是。Synthesis 會把它轉成硬體 adder。

Q4：assign a = a + b; 有什麼問題？

可能形成 combinational feedback / logic loop。

Q5：多條 assign 會按照程式順序執行嗎？

不會。它們描述同時存在、持續運作的硬體關係。

Q6：Continuous assignment 最常驅動什麼型別？

wire / net。

14. 一頁記憶版

語法

assign y = expression;

用途

描述 combinational logic。

Target

通常是 wire / net。

特性

RHS 改變 → LHS 持續更新。

常見硬體

Gate、MUX、Adder、Comparator、Decoder。

注意

避免 logic loop 與 width mismatch。

最後一句：
Continuous Assignment 的重點不是「assign 這個字」，而是建立一個 永久存在的 combinational relationship：輸入改變，輸出就依照 expression 改變。
