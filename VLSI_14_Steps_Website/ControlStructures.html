1. 控制結構是什麼？

在 Behavioral Modeling 中，控制結構用來描述「不同條件下硬體該選哪條資料路徑、執行哪個動作」。課程將 if、case、casex、casez、for 列為常見 synthesis tool 支援的 constructs。

if

條件判斷、priority logic。

case

selector / opcode / state decode。

casex / casez

wildcard / don't-care matching。

for

重複描述相似硬體。

關鍵：它們不是在 CPU 上「跑流程」，而是在描述要合成出的硬體結構。

2. if / else Statement

基本語法

if (condition)
    statement1;
else
    statement2;

例 1：2-to-1 MUX

always @(*) begin
    if (sel)
        y = b;
    else
        y = a;
end

例 2：課程中的巢狀 if 4-to-1 MUX

always @(*) begin
    if (s1) begin
        if (s0) out = i3;
        else    out = i2;
    end
    else begin
        if (s0) out = i1;
        else    out = i0;
    end
end

例 3：Priority Encoder

always @(*) begin
    if      (req[3]) code = 2'd3;
    else if (req[2]) code = 2'd2;
    else if (req[1]) code = 2'd1;
    else             code = 2'd0;
end
if / else if 有優先順序。若多個條件同時成立，最前面的條件優先。

3. case Statement

基本語法

case (expression)
    value1 : statement1;
    value2 : statement2;
    default: statement_default;
endcase

課程 4-to-1 MUX

always @(I0 or I1 or I2 or I3 or S)
case (S)
    2'b00: Y = I0;
    2'b01: Y = I1;
    2'b10: Y = I2;
    2'b11: Y = I3;
endcase

建議加入 default

always @(*) begin
    case(sel)
        2'b00: y = a;
        2'b01: y = b;
        2'b10: y = c;
        2'b11: y = d;
        default: y = 0;
    endcase
end
case 很適合 MUX、ALU opcode、FSM state decoding。

4. casex Statement

課程說明 casex 把 x 與 z 都當成 don't care，只比較非 x / z 的位置。

課程範例：Count Trailing Zeros

always @(data)
casex (data)
    4'bxxx1: out = 0;
    4'bxx10: out = 1;
    4'bx100: out = 2;
    4'b1000: out = 3;
    4'b0000: out = 4;
    default: out = 3'b111;
endcase

4'bxxx1 代表只要最低位是 1，其餘位元不重要。

實務注意：casex 可能把 simulation 中真正的未知 X 也掩蓋成 don't care，因此 RTL 使用要非常謹慎。

5. casez Statement

課程說明 casez 將 z 視為 don't care；相較 casex，它不會同樣把所有 x 都忽略。

Priority Pattern

always @(*) begin
    casez(req)
        4'b1???: code = 2'd3;
        4'b01??: code = 2'd2;
        4'b001?: code = 2'd1;
        4'b0001: code = 2'd0;
        default: code = 2'd0;
    endcase
end
? 常用作 wildcard pattern，讓不重要的位元不必逐一列出。

6. for Loop

基本語法

for (initialization; condition; update)
    statement;

課程範例：Count Zeros in a Byte

integer i;

always @(data) begin
    out = 0;
    for (i = 0; i <= 7; i = i + 1)
        if (data[i] == 0)
            out = out + 1;
end

此程式逐一檢查 8 個 bit，每遇到一個 0 就累加 out。

可合成 for loop 通常會被展開。它不代表硬體一定花 8 個 clock 跑 8 次。

7. 五種結構比較

結構適合用途特色

caseMUX / opcode / state精確 selector matching

8. 大量 Verilog 範例

例 1：if — Enable

always @(*) begin
    if (en) y = a & b;
    else    y = 0;
end

例 2：if — Max

always @(*) begin
    if (a > b) max = a;
    else       max = b;
end

例 3：if / else if — Saturation

always @(*) begin
    if      (x > 8'd200) y = 8'd200;
    else if (x < 8'd20)  y = 8'd20;
    else                 y = x;
end

例 4：if — Register Enable

always @(posedge clk)
    if (en)
        q <= d;

例 5：if — Async Reset

always @(posedge clk or negedge rst_n) begin
    if (!rst_n) q <= 0;
    else        q <= d;
end

例 6：case — 4-to-1 MUX

always @(*) begin
    case(sel)
        2'd0: y = a;
        2'd1: y = b;
        2'd2: y = c;
        2'd3: y = d;
    endcase
end

例 7：case — ALU

always @(*) begin
    case(op)
        3'b000: y = a + b;
        3'b001: y = a - b;
        3'b010: y = a & b;
        3'b011: y = a | b;
        3'b100: y = a ^ b;
        default: y = 0;
    endcase
end

例 8：case — Decoder

always @(*) begin
    case(sel)
        2'b00: y = 4'b0001;
        2'b01: y = 4'b0010;
        2'b10: y = 4'b0100;
        2'b11: y = 4'b1000;
    endcase
end

例 9：case — FSM

always @(*) begin
    next_state = state;
    case(state)
        IDLE: if (start) next_state = RUN;
        RUN : if (done)  next_state = IDLE;
        default: next_state = IDLE;
    endcase
end

例 10：casex — Priority Match

always @(*) begin
    casex(req)
        4'b1xxx: code = 2'd3;
        4'b01xx: code = 2'd2;
        4'b001x: code = 2'd1;
        4'b0001: code = 2'd0;
        default: code = 0;
    endcase
end

例 11：casez — Priority Encoder

always @(*) begin
    casez(req)
        4'b1???: code = 2'd3;
        4'b01??: code = 2'd2;
        4'b001?: code = 2'd1;
        4'b0001: code = 2'd0;
        default: code = 0;
    endcase
end

例 12：for — Count Ones

integer i;
always @(*) begin
    count = 0;
    for (i = 0; i < 8; i = i + 1)
        if (data[i])
            count = count + 1;
end

例 13：for — Reverse Bits

integer i;
always @(*) begin
    for (i = 0; i < 8; i = i + 1)
        y[i] = a[7-i];
end

例 14：for — Parity

integer i;
always @(*) begin
    parity = 0;
    for (i = 0; i < 8; i = i + 1)
        parity = parity ^ data[i];
end

例 15：for — Find First One

integer i;
always @(*) begin
    found = 0;
    pos = 0;
    for (i = 0; i < 8; i = i + 1) begin
        if (!found && data[i]) begin
            found = 1;
            pos = i;
        end
    end
end

例 16：for — Reset Register Array

integer i;
always @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin
        for (i = 0; i < 8; i = i + 1)
            regs[i] <= 0;
    end
end

9. Synthesis 觀點

if

常形成 MUX / priority MUX。

case

常形成 selection / decode logic。

for

固定範圍時通常展開成重複硬體。

課程明確把 case/casex/casez/default、if/else、for loop 列為 synthesis tools 常見支援的 language constructs。

10. Incomplete Assignment 與 Latch

錯誤

always @(*) begin
    if (en)
        y = a;
end

en=0 時 y 沒有新值，可能推導出 latch。

修正

always @(*) begin
    if (en) y = a;
    else    y = b;
end

case 也是同樣原則：要覆蓋所有情況，常用 default 或 block 一開始先給 default value。

11. 常見錯誤與考試重點

if / else if：有 priority，別忽略先後順序。
case：combinational logic 未涵蓋所有狀態可能推導 latch。
casex：可能掩蓋真實 X，實務上須謹慎。
for：不要誤以為等同「跑 N 個 clock」；固定迴圈通常被硬體展開。
累加型 for：進入 combinational block 時要先初始化 accumulator。

12. 自我測驗

Q1：if / else if 有 priority 嗎？

有，越前面的條件優先。

Q2：case 最常用於什麼？

MUX、opcode decode、state decode。

Q3：casex 把什麼當 don't care？

x 與 z。

Q4：casez 的特色？

z（以及常用 ? pattern）可作 wildcard。

Q5：for loop 8 次是否等於 8 個 clock？

通常不是；固定範圍可由 synthesis 展開成硬體。
