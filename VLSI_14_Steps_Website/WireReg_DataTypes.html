1. 基本觀念：Verilog 為什麼同時有 wire 與 reg？

Verilog 不只是程式語言，它是在描述「硬體」。因此需要區分兩種完全不同的概念：

wire：Net

像實體電路中的導線。

它本身不主動產生資料，而是把某個 driver 的值傳送到別處。

reg：Procedural Variable

像 procedural block 裡可被指定值的變數。

它在 always / initial 等程序區塊中被更新並保留目前值，直到下一次再被賦值。

drivergate / assign / module output
→
wire傳遞訊號
→
其他電路load
先背這一句：
wire 主要用來表示「連接」；reg 主要用來表示「在 procedural block 中被賦值的變數」。

2. wire：Net Type 詳細說明

課程教材把 wire 歸類為 Net，並強調它像實體電路中的 wire， 用來連接 design objects，而且必須有 driver。預設寬度是 1 bit。

2.1 最簡單宣告

wire a;
wire b;
wire y;

三者都是 1-bit net。

2.2 多位元 wire

wire [7:0] data;
wire [15:0] addr;
wire [31:0] bus;

wire [7:0] data; 代表 8 條平行的 wire： data[7] 到 data[0]。

2.3 wire 最常搭配 continuous assignment

wire y;

assign y = a & b;

這代表：只要 a 或 b 改變，y 就重新計算。 它描述的是持續存在的硬體關係。

2.4 wire 可由 gate primitive 驅動

wire y;

and (y, a, b);

這裡 AND gate 的 output 就是 y 的 driver。

2.5 wire 可由 module output 驅動

wire sum;
wire carry;

half_adder U0 (
    .a(a),
    .b(b),
    .sum(sum),
    .carry(carry)
);

half_adder 模組的輸出驅動 sum 和 carry。

直覺：如果你的訊號是「某個元件輸出接到另一個元件輸入」， 最容易先想到 wire。

3. reg：Procedural Variable 詳細說明

課程教材把 reg 與 integer 放在 Register 類別， 說明它們像一般 procedural language 的變數，可以在程式執行期間保留資訊。 reg 的預設寬度是 1 bit。

3.1 最簡單宣告

reg y;
reg flag;

3.2 多位元 reg

reg [7:0] data;
reg [15:0] counter;
reg [31:0] result;

3.3 reg 常用在 always block 內被指定

reg y;

always @(*) begin
    y = a & b;
end

因為 y 是在 procedural block 內被賦值，所以傳統 Verilog 要宣告成 reg。

3.4 reg 也可以表示真正的 register

reg q;

always @(posedge clk) begin
    q <= d;
end

這段通常會合成為 D flip-flop，所以此時 q 確實對應到硬體 register。

最重要的陷阱：reg 這個關鍵字本身不代表一定會合成出 flip-flop。
例如 always @(*) y = a & b; 中的 y 雖然宣告成 reg， 但它仍然是組合邏輯輸出。

5. 什麼叫做 driver？

Driver 可以想成「誰負責決定這條訊號目前是 0 還是 1」。

Continuous Assignment

assign y = a & b;

assign 是 y 的 driver。

Gate Output

and (y, a, b);

AND gate 是 y 的 driver。

Module Output

adder U0(...,.sum(y));

U0 的 output port 是 y 的 driver。

5.1 沒有 driver 的 wire

wire y;

// 沒有任何 assign / gate / module output 驅動 y

模擬時這類 net 通常不會有你期待的有效邏輯值。

5.2 多重 driver

wire y;

assign y = a;
assign y = b;
一般 RTL 設計應避免不必要的 multiple drivers。 若不同 driver 同時驅動相反邏輯值，模擬可能解析成未知值。

6. 大量 Verilog 例子

例 1：最基本 AND gate

module ex1(
    input  a, b,
    output y
);
    wire y;
    assign y = a & b;
endmodule

例 2：用 reg 寫同一個組合邏輯

module ex2(
    input  a, b,
    output reg y
);
    always @(*) begin
        y = a & b;
    end
endmodule
ex1 和 ex2 都是組合邏輯。
ex2 使用 reg，只是因為 y 在 always block 裡被指定，並不表示它變成 flip-flop。

例 3：2-to-1 MUX — wire 寫法

module mux2_wire(
    input  a, b, sel,
    output y
);
    wire y;
    assign y = sel ? b : a;
endmodule

例 4：2-to-1 MUX — reg 寫法

module mux2_reg(
    input  a, b, sel,
    output reg y
);
    always @(*) begin
        if (sel)
            y = b;
        else
            y = a;
    end
endmodule

例 5：4-to-1 MUX

module mux4(
    input  [3:0] d,
    input  [1:0] sel,
    output reg   y
);
    always @(*) begin
        case (sel)
            2'b00: y = d[0];
            2'b01: y = d[1];
            2'b10: y = d[2];
            2'b11: y = d[3];
        endcase
    end
endmodule

例 6：1-bit Full Adder — wire

module fa_wire(
    input  a, b, cin,
    output sum, cout
);
    wire sum, cout;

    assign sum  = a ^ b ^ cin;
    assign cout = (a & b) | (a & cin) | (b & cin);
endmodule

例 7：1-bit Full Adder — reg

module fa_reg(
    input  a, b, cin,
    output reg sum, cout
);
    always @(*) begin
        {cout, sum} = a + b + cin;
    end
endmodule

例 8：Comparator

module compare8(
    input [7:0] a, b,
    output gt, eq, lt
);
    wire gt, eq, lt;

    assign gt = (a > b);
    assign eq = (a == b);
    assign lt = (a < b);
endmodule

例 9：ALU output 用 reg

module alu8(
    input  [7:0] a, b,
    input  [2:0] op,
    output reg [7:0] y
);
    always @(*) begin
        case (op)
            3'b000: y = a + b;
            3'b001: y = a - b;
            3'b010: y = a & b;
            3'b011: y = a | b;
            3'b100: y = a ^ b;
            default: y = 8'h00;
        endcase
    end
endmodule

例 10：真正會合成成 Flip-Flop 的 reg

module dff(
    input  clk,
    input  d,
    output reg q
);
    always @(posedge clk) begin
        q <= d;
    end
endmodule

例 11：Register with Reset

module reg8(
    input        clk,
    input        rst_n,
    input  [7:0] d,
    output reg [7:0] q
);
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n)
            q <= 8'h00;
        else
            q <= d;
    end
endmodule

例 12：Counter

module counter8(
    input        clk,
    input        rst_n,
    input        en,
    output reg [7:0] count
);
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n)
            count <= 8'd0;
        else if (en)
            count <= count + 1'b1;
    end
endmodule

例 13：中間接線用 wire，state 用 reg

module datapath(
    input        clk,
    input  [7:0] a, b,
    output reg [7:0] q
);
    wire [7:0] sum;

    assign sum = a + b;   // combinational net

    always @(posedge clk) begin
        q <= sum;         // q is stored in FFs
    end
endmodule
a,b
→
Addersum 是 wire
→
Registerq 是 reg

例 14：FSM 中 wire / reg 的角色

reg state;
reg next_state;
wire go;

assign go = start & ready;

always @(posedge clk or negedge rst_n) begin
    if (!rst_n)
        state <= 1'b0;
    else
        state <= next_state;
end

always @(*) begin
    next_state = state;

    if (go)
        next_state = ~state;
end

go 是組合條件 → wire 很自然；state 和 next_state 在 procedural blocks 裡賦值 → reg。

7. wire / reg 與組合邏輯、時序邏輯的關係

電路 典型寫法 常見型別
組合邏輯（continuous assignment） assign y = a & b; y → wire
組合邏輯（procedural） always @(*) y = a & b; y → reg
時序邏輯 always @(posedge clk) q <= d; q → reg
所以：
wire 常見於組合邏輯，但「wire = 組合」不是定義。
reg 可出現在組合或時序邏輯，因此「reg = flip-flop」也是錯誤的。

8. input / output 與 wire / reg

8.1 output 由 assign 驅動

module ex(
    input a, b,
    output y
);
    assign y = a & b;
endmodule

傳統 Verilog 中，這種 output 本質上是 net 型別，適合用 continuous assignment 驅動。

8.2 output 在 always 裡賦值

module ex(
    input a, b,
    output reg y
);
    always @(*) begin
        y = a & b;
    end
endmodule
判斷 output 要不要寫 reg 的快速方法：
如果它在 always / initial procedural block 裡被賦值，傳統 Verilog 通常宣告成 reg。

9. Vector：多位元 wire 與 reg

9.1 wire bus

wire [7:0] bus;
wire [3:0] low_nibble;

assign low_nibble = bus[3:0];

9.2 reg vector

reg [7:0] counter;

always @(posedge clk) begin
    counter <= counter + 1'b1;
end

9.3 bit select 與 part select

wire [15:0] data;

wire msb;
wire [7:0] high_byte;

assign msb       = data[15];
assign high_byte = data[15:8];

10. 常見錯誤與考試陷阱

錯誤 1：在 always block 內對 wire 賦值

// 傳統 Verilog：錯誤示範
wire y;

always @(*) begin
    y = a & b;
end

procedural assignment 的目標應該是 reg 類型。

錯誤 2：把 reg 理解成一定是 register

reg y;

always @(*) begin
    y = a & b;
end

這是組合邏輯，通常只合成成 AND gate，不會因為用了 reg 就自動多一顆 FF。

錯誤 3：組合 always 未完整賦值

reg y;

always @(*) begin
    if (en)
        y = a;
end
當 en=0 時，y 沒有新值，工具可能推導出 latch。

正確：給所有條件完整賦值

always @(*) begin
    if (en)
        y = a;
    else
        y = b;
end

錯誤 4：clocked logic 使用 blocking assignment

// 不推薦的 RTL coding style
always @(posedge clk) begin
    q = d;
end

一般建議

// sequential
always @(posedge clk)
    q <= d;

// combinational
always @(*)
    y = a & b;
常見 coding guideline：
Combinational procedural logic → blocking =
Sequential clocked logic → nonblocking <=

11. 補充：SystemVerilog 的 logic

這一節是延伸補充，不是課程投影片中 wire / reg 基本定義本身。 SystemVerilog 引入 logic，可以讓許多 RTL 宣告更直觀。 

logic y;

always_comb begin
    y = a & b;
end

不過在學習傳統 Verilog 時，先把 wire = net、reg = procedural variable 的差異理解清楚非常重要，因為這能幫助你理解 driver、continuous assignment 與 procedural assignment。

12. 自我測驗

Q1：assign y = a & b; 中，y 應該宣告成 wire 還是 reg？

傳統 Verilog：wire。

Q2：always @(*) y = a & b; 中，y 應該宣告成什麼？

傳統 Verilog：reg，因為 y 在 procedural block 中被賦值。

Q3：reg y; 是否代表一定有 flip-flop？

不是。是否合成成 flip-flop 取決於描述方式，例如是否在 clock edge 上更新。

Q4：wire 的值從哪裡來？

從 driver，例如 assign、gate output 或 module output。

Q5：output reg y; 一定是時序電路嗎？

不是。若 y 在 always @(*) 中完整賦值，仍可合成成純組合邏輯。

Q6：為什麼 counter 常宣告成 reg？

因為它通常在 clocked always block 裡被 procedural assignment 更新，而且要跨 clock 保存狀態。

13. 最後一頁記憶版

wire

像導線。

需要 driver。

常搭配 assign、gate、module instance。

預設 1 bit。

reg

像 procedural variable。

在 always / initial 中被賦值。

可以描述組合邏輯，也可以描述時序邏輯。

預設 1 bit。

最重要的一句：
wire 與 reg 的差異首先是「訊號如何被驅動與賦值」， 而不是簡單地把它們等同於「組合邏輯」與「暫存器」。
