1. NLDM 是什麼？

NLDM = Non-Linear Delay Model。 課程明確指出：cell delay 不是只存成單一常數，而是以 2D lookup table 的形式儲存，其兩個 index 是：

Index 1

Input Slew
也就是 Input Transition Time。

Index 2

Output Load Capacitance
也就是這顆 cell 輸出端所看到的負載。

Input Slew
+
Output Load
→
查 NLDM Table
→
Cell Delay
一句話：NLDM 就是「用 Input Slew 與 Output Load 兩個條件，查表得到 Standard Cell Delay」。

2. 為什麼叫 Non-Linear Delay Model？

如果 delay 永遠只是：

Delay = 常數

就不需要 lookup table。但真實 CMOS cell 的 delay 會隨輸入邊緣速度、輸出負載、 PVT 等條件改變，而且變化通常不能簡單用單一線性公式完整描述。

概念比較

模型想法問題
固定 Delay每顆 INV 都是 30 ps忽略 slew / load
簡單線性模型delay = a + b×load無法完整表達複雜行為
NLDM對不同 slew/load 建立表格更貼近 characterization data
課程只明確說明 delay 以 Input Slew × Output Load 的 2D lookup table 表示； 「與簡單線性模型比較」是為理解 Non-Linear 一詞而加入的教學延伸。

3. NLDM 的兩個 Index

3.1 Input Slew

代表訊號輸入這顆 cell 時，上升或下降邊緣有多快。 

Fast slew:
____/‾‾‾‾

Slow slew:
______/‾‾‾

3.2 Output Load Capacitance

代表輸出端需要驅動多少 capacitance。 可能包含下一級 gate input capacitance，以及 interconnect parasitic capacitance。 

Small load:
INV1 ───→ INV2

Large load:
            → INV2
INV1 ───────→ NAND
            → MUX
            → DFF
Input Slew 是「輸入怎麼進來」；Output Load 是「輸出要拖多重」。

4. 2D Lookup Table 怎麼讀？

下面是一張教學用假設資料表：

Input Slew ↓ / Load →2 fF10 fF30 fF60 fF
10 ps18 ps24 ps37 ps55 ps
30 ps23 ps30 ps44 ps64 ps
60 ps31 ps39 ps54 ps75 ps
100 ps43 ps52 ps68 ps92 ps
上表數值是為解釋 NLDM 而自訂的示意值，不是課程投影片的實際 cell 數據。

例：Input Slew = 30 ps，Load = 30 fF

直接找 row = 30 ps、column = 30 fF：

Cell Delay = 44 ps

例：Input Slew = 100 ps，Load = 60 fF

Cell Delay = 92 ps

你可以直接看出：在這個示意表中，slew 越慢、load 越大，delay 越大。

5. Input Slew 為什麼會影響 Delay？

如果 input transition 很慢，MOS transistor 的導通狀態也會比較緩慢地變化， 因此輸出充放電行為會受到影響。

例 1：同樣 Load，不同 Slew

Input SlewOutput Load示意 Delay
10 ps30 fF37 ps
30 ps30 fF44 ps
60 ps30 fF54 ps
100 ps30 fF68 ps

Load 都固定 30 fF，只有 input slew 變慢，delay 也跟著改變。

這就是為什麼 STA 不只看「這顆 cell 是 INV_X1」； 它還必須知道「這次進入 INV_X1 的 input slew 是多少」。

6. Output Load 為什麼會影響 Delay？

輸出端本質上要對 capacitance 充電或放電。 負載越大，需要搬運的 charge 越多，因此 cell response 通常會變慢。

例 2：同樣 Slew，不同 Load

Input SlewOutput Load示意 Delay
30 ps2 fF23 ps
30 ps10 fF30 ps
30 ps30 fF44 ps
30 ps60 fF64 ps

Fanout 概念

INV_X1 → 1 gate
    load small

INV_X1 → 8 gates
    load larger

因此 high-fanout net 往往會有較大的 capacitive load。

7. Rise Delay / Fall Delay 為什麼通常分開？

本節是標準 cell timing model 的延伸說明；課程片段沒有逐項列出 cell_rise / cell_fall， 但它與課程介紹的 cell delay / slew characterization 一致。

以 inverter 為例：

InputOutput主要輸出行為
0 → 11 → 0Output falling
1 → 00 → 1Output rising

PMOS 與 NMOS network 的特性可能不同，所以 output rise 與 output fall 通常會各自有 timing table。 

cell_rise(...)
cell_fall(...)
rise_transition(...)
fall_transition(...)

8. 如果 Slew / Load 不剛好在表格格點上？

Interpolation 是理解 lookup table 實際使用方式的延伸說明； 課程頁面明確支持的是 2D lookup table 與兩個 index，本頁不把 interpolation 細節視為投影片原文。

假設 table 只有： 

Input Slew : 30 ps, 60 ps
Load       : 10 fF, 30 fF

但現在實際條件是： 

Input Slew = 45 ps
Load       = 20 fF

它位於四個已知 table points 中間，因此 EDA tool 會依 timing model 規則， 利用附近的 table values 推估對應 delay。

四個附近點

10 fF30 fF
30 psD11D12
60 psD21D22

可把概念想成「二維內插」。

先沿一個方向估值，再沿另一個方向估值 → 得到中間條件的 delay

9. NLDM 在 Liberty .lib 裡可能長什麼樣？

課程指出 .lib/.db 是 Timing & Power View， 其中包含 propagation delay、setup/hold、dynamic/leakage power，並使用 NLDM / CCS 等模型。

示意 Liberty 結構

cell (INV_X1) {
    pin (A) {
        direction : input;
    }

    pin (ZN) {
        direction : output;
        function : "!A";

        timing() {
            related_pin : "A";

            cell_rise(delay_template) {
                index_1("0.01, 0.03, 0.06, 0.10");
                index_2("0.002, 0.010, 0.030, 0.060");

                values(
                    "0.018, 0.024, 0.037, 0.055",
                    "0.023, 0.030, 0.044, 0.064",
                    "0.031, 0.039, 0.054, 0.075",
                    "0.043, 0.052, 0.068, 0.092"
                );
            }
        }
    }
}
這段 Liberty 是教學示意，不是課程提供的實際 cell library 內容。

10. 大量 NLDM 例子

例 1：INV_X1，小 Slew、小 Load

Slew = 10 ps
Load = 2 fF
→ 查表
→ Delay ≈ 18 ps  （示意）

例 2：INV_X1，小 Slew、大 Load

Slew = 10 ps
Load = 60 fF
→ Delay ≈ 55 ps

只增加 load，delay 就明顯上升。

例 3：INV_X1，慢 Slew、小 Load

Slew = 100 ps
Load = 2 fF
→ Delay ≈ 43 ps

即使 load 很小，input slew 太慢仍會使 delay 變大。

例 4：最差組合

Slew = 100 ps
Load = 60 fF
→ Delay ≈ 92 ps

Slow input + large load 通常是不利 timing 的組合。

例 5：Buffer Chain

INV1 → INV2 → INV3

INV1 的 output slew 會成為 INV2 的 input slew； INV2 的 output slew 又會成為 INV3 的 input slew。 因此 slew 會逐級傳遞。

例 6：下一級輸入 capacitance 形成 Load

INV1 ─→ NAND2
        ↑
   NAND2 input capacitance

NAND2 input pin capacitance 會成為 INV1 output load 的一部分。

例 7：High Fanout Control Signal

enable → FF1
       → FF2
       → FF3
       → FF4
       → ...
       → FF20

enable net 驅動很多 inputs，load 增加，driver delay / output transition 可能惡化。

例 8：Cell Upsizing

INV_X1  timing too slow
    ↓
INV_X2
    ↓
INV_X4

更強 drive 的 cell 可能降低大 load 下的 delay，但通常會增加 area / power / input capacitance。

例 9：Upsizing 也可能讓前級更重

Stage1 → INV_X1
          ↓ replace
Stage1 → INV_X4

INV_X4 的 input capacitance 可能更大，因此雖然它自己能更快驅動後級， 卻可能讓 Stage1 的 output load 增加。

這就是 timing optimization 為什麼不能只看單一 cell，而要看整條 path。

例 10：NAND2 不同 Input Slew

A transition: 15 ps
B held at enabling value
Load: 20 fF

vs.

A transition: 80 ps
B held at enabling value
Load: 20 fF

即使 cell 與 load 相同，不同 input slew 也會對 delay 造成不同結果。

例 11：MUX Data Path

A ----\
       MUX2 ---- Y
B ----/
       S

MUX 的 data input / select input 可以形成不同 timing arcs；每條 arc 都可能有自己的 characterized table。

例 12：DFF Clock-to-Q

CLK ↑
   ↓
DFF ---- Q
        ↑
      Load

Sequential cell 的 output timing 同樣會受到 output load 影響；課程的 .lib/.db 內容也包含 setup/hold timing。

例 13：Critical Path

FF1 → NAND2 → AOI → INV → MUX → FF2

STA 會逐級計算： 

FF1 Q slew
→ NAND2 input slew
→ NAND2 查表得到 delay + output slew
→ AOI input slew
→ AOI 查表
→ INV 查表
→ MUX 查表
→ arrival time at FF2

例 14：Wire Capacitance 增加

Before routing:
Driver → short net → Load

After routing:
Driver ───────────── long wire ─────→ Load

實體線路的 parasitic capacitance 增加後，effective output load 改變， timing analysis 也必須重新計算。

例 15：Same Logic, Different PVT

INV_X1 at Corner A
INV_X1 at Corner B
INV_X1 at Corner C

每個 PVT corner 都可能有不同 characterization data，因此同一顆 cell 的 NLDM table 也會依 library corner 不同。

11. STA 如何逐級使用 NLDM？

課程說明 NLDM 的 delay table 由 Input Slew 與 Output Load 索引。 因此在一條 timing path 中，分析不是「每顆 cell 加固定 delay」， 而是逐級傳播 arrival time 與 slew。

概念流程

Stage 1 Input Slew
→
查 Stage 1 NLDM
→
Delay + Output Slew
→
Stage 2 Input Slew
→
繼續查表

簡化數值例子

FF Q arrival = 100 ps

NAND delay = 40 ps
→ arrival = 140 ps

INV delay = 25 ps
→ arrival = 165 ps

MUX delay = 55 ps
→ arrival = 220 ps
上面數字為示意。實際每一級 delay 會依該級 input slew 與 output load 查對應 library table。

12. NLDM 與 Cell Sizing / Timing Optimization

因為不同 drive strength 的 cells 有不同 timing tables， synthesis / optimization tool 可以比較：

CellDriveAreaInput Cap對大 Load 的能力
INV_X1弱小小較弱
INV_X2中中中較好
INV_X4強大大更好

課程 Standard Cell Library 的概念也指出，library 會有不同 drive-strength variants， 讓工具在 area、delay、load capacitance 之間取捨。

Optimization 思考

如果某級 delay 太大：
1. 換強一點的 cell？
2. 插 buffer？
3. 減少 fanout？
4. 改變 logic structure？
5. 重新 placement / routing？

13. NLDM 的限制

本節是延伸理解。課程投影片同頁只說明 NLDM 的 2D lookup-table 形式， 而 `.lib/.db` 頁面也同時提到 NLDM / CCS models。

NLDM 的主要優點是簡單、查表快、容易被 STA 使用。 但它把複雜 waveform behavior 濃縮成 input slew 與 output load 等參數， 因此對非常進階的波形效應，其他模型可能提供更細緻描述。

NLDM 優點

查表快速、資料結構直觀、適合大規模 STA。

較進階模型

課程的 library-format 頁面同時提到 CCS，表示 timing/power library 並不只限 NLDM。

14. 常見誤解與考試重點

誤解 1：NLDM = 一顆 cell 一個 delay

錯。課程明確說是 2D lookup table。

誤解 2：NLDM 只看 Output Load

錯。還要看 Input Slew。

誤解 3：Input Slew 就是 Clock Frequency

錯。Slew 是單次訊號 edge 的 transition time，不是週期或頻率。

誤解 4：Output Load 只等於下一顆 gate 數量

不完整。真正關心的是等效 capacitance；不同 cells 的 pin capacitance 不同，interconnect 也會貢獻 parasitic capacitance。

誤解 5：每一級 timing 可以完全獨立算

錯。上一級 output slew 會成為下一級 input slew，因此 stage 之間彼此相依。

誤解 6：NLDM Table 數字是 RTL 模擬產生的

錯。課程指出 cell characterization 來自大量 transistor-level SPICE simulations。

15. 自我測驗

Q1：NLDM 全名？

Non-Linear Delay Model。

Q2：NLDM 兩個主要 table index？

Input Slew（Transition Time）與 Output Load Capacitance。

Q3：Input Slew 變慢時，為什麼不能仍使用相同 delay？

因為 transistor 的驅動建立過程改變，characterized cell response 也會不同。

Q4：Output Load 增大時，為什麼 delay 常增加？

因為輸出端需要對更大的 capacitance 充放電。

Q5：NLDM data 主要放在哪一類 library view？

Timing & Power View，也就是課程所列的 `.lib/.db`。

Q6：上一級 output slew 與下一級有何關係？

上一級 output slew 會成為下一級的 input slew，是 STA 逐級 propagation 的重要資訊。
