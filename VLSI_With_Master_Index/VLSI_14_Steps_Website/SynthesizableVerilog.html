1. 什麼叫 Synthesizable Verilog？

Verilog 語法很多，但不是每一種語法都一定能轉成 gates、flip-flops、muxes、adders 等真實硬體。 Synthesizable Verilog 指的是 synthesis tool 能理解並轉換成硬體結構的 Verilog 子集。

Simulation

只要 simulator 能執行即可，允許很多測試、時間控制與模擬專用行為。

Synthesis

描述必須可以對應成有限、明確、可實作的數位硬體。

一句話：能模擬 ≠ 一定能合成；能合成的 RTL 必須能對應成真實硬體。

4. Module / Port / Parameter

4.1 基本可合成模組

module and2(
    input  a,
    input  b,
    output y
);
    assign y = a & b;
endmodule

4.2 Named Port Binding

and2 U0(
    .a(in1),
    .b(in2),
    .y(out)
);

4.3 Positional Port Binding

and2 U0(in1, in2, out);

4.4 localparam

localparam IDLE = 2'b00;
localparam RUN  = 2'b01;
localparam DONE = 2'b10;
Named port binding 可讀性通常更好，尤其 port 數量多時較不容易接錯。

5. wire / reg / integer

5.1 wire

wire y;
assign y = a & b;

5.2 reg

reg y;
always @(*) begin
    y = a & b;
end

5.3 integer 作為 for loop index

integer i;

always @(*) begin
    count = 0;
    for (i = 0; i < 8; i = i + 1)
        count = count + data[i];
end

6. Continuous Assignment

Continuous assignment 是課程明確列出的 synthesis-supported construct。

AND

assign y = a & b;

MUX

assign y = sel ? b : a;

Adder

assign {cout, sum} = a + b;

Comparator

assign eq = (a == b);

Shift

assign y = a << 2;

Concatenation

assign y = {a[3:0], b[3:0]};

雖然課程列出 arithmetic operators 為常見支援項目，但不同 operator 的硬體成本差很多；例如乘除法通常比簡單 AND/OR 更昂貴。

8. Procedural Blocks

8.1 Combinational

always @(*) begin
    y = (a & b) | c;
end

8.2 Sequential

always @(posedge clk) begin
    q <= d;
end

8.3 Resettable Register

always @(posedge clk or negedge rst_n) begin
    if (!rst_n)
        q <= 0;
    else
        q <= d;
end

9. if / case / for

if → MUX / Priority Logic

always @(*) begin
    if (sel)
        y = b;
    else
        y = a;
end

case → Multi-way Selection

always @(*) begin
    case(op)
        2'b00: y = a + b;
        2'b01: y = a - b;
        2'b10: y = a & b;
        default: y = a | b;
    endcase
end

for → Repeated Hardware

integer i;
always @(*) begin
    parity = 0;
    for (i = 0; i < 8; i = i + 1)
        parity = parity ^ data[i];
end
for loop 在可合成 RTL 中通常代表「展開重複硬體」，不是讓 CPU 逐次執行。

10. Task 與 Function

課程將 task 與 function 列為常見 synthesis-supported constructs；其中 task 特別註明 no timing or event control。

10.1 Function：Parity

function parity8;
    input [7:0] data;
    begin
        parity8 = ^data;
    end
endfunction

assign p = parity8(din);

10.2 Function：Max

function [7:0] max8;
    input [7:0] a, b;
    begin
        if (a > b)
            max8 = a;
        else
            max8 = b;
    end
endfunction

10.3 Task：無 timing control 的組合運算

task calc;
    input  [7:0] a, b;
    output [7:0] sum;
    begin
        sum = a + b;
    end
endtask
依課程條件，可合成 task 不應包含像 #10、@(posedge clk) 這類 timing / event control。

11. 可合成 Combinational RTL 的典型形式

11.1 MUX

always @(*) begin
    case(sel)
        2'b00: y = a;
        2'b01: y = b;
        2'b10: y = c;
        default: y = d;
    endcase
end

11.2 ALU

always @(*) begin
    case(op)
        3'b000: result = a + b;
        3'b001: result = a - b;
        3'b010: result = a & b;
        3'b011: result = a | b;
        3'b100: result = a ^ b;
        default: result = 0;
    endcase
end

11.3 Priority Encoder

always @(*) begin
    if      (req[3]) code = 2'd3;
    else if (req[2]) code = 2'd2;
    else if (req[1]) code = 2'd1;
    else             code = 2'd0;
end
Combinational procedural block 要讓所有可能路徑都有明確輸出，避免不小心推導 latch。

12. 可合成 Sequential RTL 的典型形式

12.1 DFF

always @(posedge clk)
    q <= d;

12.2 Register Enable

always @(posedge clk) begin
    if (en)
        q <= d;
end

12.3 Counter

always @(posedge clk or negedge rst_n) begin
    if (!rst_n)
        count <= 0;
    else if (en)
        count <= count + 1'b1;
end

12.4 Shift Register

always @(posedge clk) begin
    q <= {din, q[7:1]};
end

12.5 FSM State Register

always @(posedge clk or negedge rst_n) begin
    if (!rst_n)
        state <= IDLE;
    else
        state <= next_state;
end

例 10：Saturating Logic

    if (x > 8'd200)
        y = 8'd200;
    else

例 11：DFF

例 12：Pipeline

always @(posedge clk) begin
    s1 <= din;
    s2 <= s1;
    s3 <= s2;

例 13：Counter + Enable

always @(posedge clk or negedge rst_n) begin
    if (!rst_n) count <= 0;
    else if (en) count <= count + 1;
end

例 14：FSM Next-State

always @(*) begin
    next_state = state;
    case(state)
        IDLE: if (start) next_state = RUN;
        RUN : if (done)  next_state = IDLE;
        default: next_state = IDLE;
    endcase
end

例 15：Hierarchical Module

half_adder U0(.a(a), .b(b), .sum(s0), .carry(c0));

assign cout = c0 | c1;

    input [7:0] x;
    begin
        inc8 = x + 1'b1;
    end

assign y = inc8(a);

14. 可合成 RTL 與純模擬寫法的區別

以下是延伸說明：課程投影片這兩頁主要列出「常見被 synthesis tool 支援的 constructs」； 下面的對照是實務觀念補充，用來幫助你判斷 RTL 與 testbench。
寫法一般用途判斷
assign y = a & b;組合硬體典型可合成
always @(posedge clk)FF / register典型可合成
for(i=0;i<8;i=i+1)固定重複硬體常可合成
#10 a = 1;simulation delay一般不作為 ASIC RTL 硬體描述
always #5 clk = ~clk;testbench clock generator典型 testbench 用法
$display(...)模擬輸出simulation-oriented
$finish停止模擬testbench
不同 synthesis tool / FPGA / ASIC flow 的實際支援範圍可能不同，因此「可合成子集」最終仍需以使用的 synthesis tool 文件與課程要求為準。

15. 實務 Coding Rules

Combinational

使用 always @(*) 或 assign。

procedural assignment 通常用 =。

所有路徑都要有輸出值。

Sequential

使用 clock edge event。

通常使用 <=。

Reset / enable 行為要明確。

判斷技巧：看到一段 Verilog，先問自己「這段可以畫成什麼硬體？」如果很難對應成有限 gates / muxes / FFs / arithmetic blocks，就要懷疑它是否只是 simulation construct。

16. 自我測驗

Q1：所有 Verilog 語法都能 synthesis 嗎？

不是。課程列出的是 synthesis tools 常見支援的子集。

Q2：continuous assignment 是否屬於課程列出的可合成 constructs？

是。

Q3：if、case、for 是否在課程支援清單中？

是。

Q4：task 有什麼特別限制？

課程註明 synthesis-supported task 不含 timing 或 event control。

Q5：for loop 是否代表硬體一定花 N 個 clock 執行？

不是。固定次數的可合成 for 常被 synthesis 展開。

Q6：always #5 clk=~clk; 適合一般 ASIC RTL 嗎？

通常是 testbench clock generator，而不是一般 synthesizable clock-generation RTL。
