1. Digital IC Flow 整體概念

數位 IC 設計不是「寫完 Verilog → 晶片完成」。 它是一條從高階功能描述逐漸下降到實體幾何與製造資料的流程。

Specification要做什麼？
→
Architecture怎麼分模組？
→
RTLVerilog/SystemVerilog
→
Simulation功能正確？
→
Synthesis轉成 gates/cells
→
Physical DesignPlacement / Routing
→
Sign-offTiming / DRC / LVS
→
GDSII / Tape-out
核心：每一層都在回答不同問題：
功能對不對？→ RTL / Simulation
硬體能不能合成？→ Synthesis
時序過不過？→ STA
版圖能不能製造？→ DRC / LVS
最後才進入 fabrication。

後面所加入的 RTL、STA、floorplan、placement、CTS、routing、DRC/LVS、GDSII 等， 是用現代數位 ASIC flow 來展開課程圖中的各階段；若投影片未逐一寫出，我會以「延伸實務」來說明。

3. System Specification：先定義「晶片要做什麼」

Specification 是整個 flow 的起點。還沒有 Verilog，先把需求寫清楚。

例 1：8-bit Counter

需求：
1. 8-bit output
2. 每個 rising edge +1
3. active-low reset
4. reset 後輸出 0

例 2：FIR Filter

需求：
Input : 16-bit signed sample
Output: 32-bit signed result
Clock : 100 MHz
Latency: <= 8 cycles
Throughput: 1 sample / cycle

例 3：CPU

ISA           : RV32I
Pipeline      : 5 stages
Clock target  : 500 MHz
Cache         : optional
Interrupt     : required
Area / Power  : constrained
Specification 不完整，後面每一層都可能反覆重做。

4. Functional / Architecture Design

Architecture Design 決定「功能要怎麼拆、資料怎麼流、需要哪些硬體資源」。 課程強調 higher level abstraction 可以協助評估不同 architecture tradeoffs。

例：乘加器 y = a×b + c

Architecture A：單週期

a,b → multiplier → adder → y

Latency 小，但 critical path 可能很長。

Architecture B：Pipeline

a,b → multiplier → REG → adder → REG

Latency 增加，但較容易提高 clock frequency。

例：影像處理

Pixel Stream
   ↓
Line Buffer
   ↓
3×3 Window
   ↓
Gaussian Filter
   ↓
Threshold
   ↓
Output

5. RTL Design：把 Architecture 寫成 Verilog / SystemVerilog

RTL = Register Transfer Level，描述 combinational logic、register、FSM 與資料傳輸。

Counter RTL

always @(posedge clk or negedge rst_n) begin
    if (!rst_n)
        count <= 8'd0;
    else
        count <= count + 1'b1;
end

MUX RTL

always @(*) begin
    case(sel)
        2'b00: y = d0;
        2'b01: y = d1;
        2'b10: y = d2;
        2'b11: y = d3;
    endcase
end

Pipeline RTL

always @(posedge clk) begin
    stage1 <= a * b;
    stage2 <= stage1 + c;
end
RTL 的工作是清楚表達硬體行為，不是手動決定每一顆 standard cell。

6. Functional / RTL Simulation：先證明功能正確

在 synthesis 前，先用 testbench 驗證 RTL。 課程傳統 flow 將 Functional Simulation 放在高階設計旁。

Counter Testbench

initial begin
    rst_n = 0;
    #20 rst_n = 1;

    #100;
    $finish;
end

always #5 clk = ~clk;

要檢查什麼？

檢查例子
功能Counter 是否每 cycle +1
ResetReset 是否回 0
Corner Case255 + 1 是否 wrap 到 0
Protocolvalid/ready handshake 是否正確
Latency輸入後第幾個 cycle 得到輸出

7. Logic Synthesis：RTL → Gate-Level Netlist

Synthesis tool 讀取 RTL 與 standard-cell library， 做 inference、logic optimization 與 technology mapping。 課程也直接展示 Before synthesis / After synthesis 的 logic optimization 概念。

RTL
→
InferenceMUX / FF / Adder
→
Optimization
→
Technology Mapping
→
Gate-Level Netlist

例：RTL

assign y = (a & b) | (a & c);

Tool 可能最佳化

y = a & (b | c);

再映射到 cells

OR2_X1  U1 (...);
AND2_X1 U2 (...);

8. Gate-Level Netlist

Gate-Level Netlist 主要描述 standard-cell instances 與 connectivity。

RTL

always @(posedge clk)
    q <= d;

Gate-Level 示意

DFF_X1 U_Q (
    .D(d),
    .CK(clk),
    .Q(q)
);

Full Adder

課程同時提供 behavioral、dataflow、gate-level 描述， 可以清楚看出抽象層下降後，結構資訊越來越明確。

9. Circuit Design

課程 Traditional VLSI Design Flow 在 Logic Synthesis 之後列出 Circuit Design， 並搭配 circuit analysis / structural representation。

在 standard-cell-based 數位 ASIC flow 裡，設計者通常不會對每一個 synthesized logic gate 都重新手刻 transistor circuit； 大量 transistor-level circuit 細節已封裝在 standard-cell library 中。 本節依課程的傳統 VLSI flow 解釋其抽象層位置。

例：Inverter

Logic:
Y = ~A

Circuit:
PMOS pull-up
NMOS pull-down

10. Physical Synthesis / Physical Design

課程的下一階段是 Physical Synthesis，並以 geometrical representation 表示版圖層級。 在現代數位 flow 中，可以進一步拆成：

Floorplan

決定 die/core、macro、I/O、power structure。

Placement

把 standard cells 放到 rows。

CTS

建立 clock tree。

Routing

把 nets 以 metal wires 接起來。

Optimization

修 timing、fanout、slew、congestion。

Floorplan 例子

+--------------------------------+
| IO                         IO  |
|                                |
|   SRAM      CPU Core           |
|                                |
|       DSP / Accelerator        |
|                                |
| IO                         IO  |
+--------------------------------+

Placement 例子

Row 1: INV DFF NAND MUX DFF ...
Row 2: AND BUF AOI  DFF INV ...
Row 3: ...

11. Extraction / Verification / Sign-off

課程 Physical Synthesis 階段旁明確標示 Extraction & Verification。 在現代數位 IC flow 裡，常見 sign-off 項目可進一步理解為：

項目目的
Parasitic Extraction取得 wire R/C 寄生參數
STA檢查 setup / hold / timing path
DRC版圖是否符合製程設計規則
LVSLayout connectivity 是否與電路/netlist 一致
Power / IR / EM延伸實務：檢查供電與可靠度

STA 例子

FF1 → NAND → INV → MUX → FF2

arrival time
+ cell delay
+ wire delay
→ check setup at FF2

DRC 例子

Metal spacing too small
→ DRC violation
→ reroute / adjust geometry

LVS 例子

Schematic / Netlist says:
A → INV → Y

Layout extracted says:
A → NAND → Y

→ mismatch
→ LVS fail

15. 出錯時，要退回哪一層？

問題可能回去修改
功能錯Specification / Architecture / RTL
RTL simulation failRTL / testbench
Synthesis errorRTL coding style / constraints
Timing failArchitecture / RTL / cell sizing / placement / routing
CongestionFloorplan / placement / architecture
DRC failRouting / physical geometry
LVS failNetlist / layout connectivity
Digital IC flow 不是只往前走，而是不斷「設計 → 驗證 → 發現問題 → 回上一層修正」。

16. 常見誤解與考試重點

誤解 1：RTL Simulation 通過，就代表晶片一定能做

錯。還要 synthesis、timing、physical verification 等。

誤解 2：Synthesis 後就完成 IC

錯。Synthesis 只得到 gate-level structural representation，還沒有 placement / routing。

誤解 3：Gate-Level Netlist = GDS

錯。Netlist 是 connectivity；GDS 是完整 physical geometry。

誤解 4：Physical Design 只是在畫漂亮版圖

錯。要同時處理 timing、routing、clock、power、design rules 等限制。

誤解 5：DRC 與 LVS 是同一件事

錯。DRC 檢查幾何規則；LVS 檢查 layout connectivity 是否對得上電路。

誤解 6：設計流程一定是單向的

錯。實際上會反覆迭代，甚至從 physical timing 問題退回 architecture 修改。

17. 自我測驗

Q1：Digital IC flow 的起點是什麼？

System Specification，先定義晶片要完成的功能與限制。

Q2：RTL 的下一個重要驗證階段是什麼？

Functional / RTL Simulation。

Q3：Synthesis 把 RTL 轉成什麼？

映射到 standard cells 的 Gate-Level Netlist。

Q4：Physical Design 常包含哪些步驟？

延伸實務上常包含 floorplan、placement、CTS、routing 與 physical optimization。

Q5：DRC 與 LVS 差在哪？

DRC 查 physical geometry rule；LVS 查 layout circuit connectivity 是否與 reference circuit/netlist 一致。

Q6：課程 Traditional VLSI Flow 最後兩個階段？

Fabrication → Packaging。
