1. Standard Cell Library 是什麼？

課程把 Standard Cell Library 定義成數位 IC 設計的基本 building block。 一個 library 就是一整套已經事先設計、驗證、characterize 過的標準元件集合。

RTLif / case / + / FF
→
Synthesis
→
Standard Cell LibraryINV / NAND / MUX / DFF...
→
Gate-Level Netlist
一句話：Standard Cell Library 就是 synthesis 與 physical design 用來「蓋晶片」的一盒標準化積木。

2. 為什麼課程說它像 LEGO？

因為每顆 cell 都像預先做好的積木：功能固定、尺寸與 pin 位置已知、timing / power 已量好， 設計工具不需要每次從 transistor 重新設計。

功能已知

例如 INV、NAND2、MUX2、DFF。

Area 已知

工具知道每顆 cell 佔多少面積。

Timing 已知

delay、slew、setup/hold 等已被 characterize。

Power 已知

dynamic / leakage power 有模型。

課程以 Nangate OpenCell Library 為例，指出 virtual 45 nm library 有 134 cells、31 個 categories， 包含 AND、AOI、BUF、CLKBUF、DFF、DFFS、FA、HA、INV、MUX、NAND 等。

5. Drive Strength：X1 / X2 / X4 / X8

同一個 Boolean function 往往有不同 drive strength 版本。 課程指出基本邏輯功能可有 1X、2X、4X、8X 等 variants， 讓 synthesis tool 在 area、delay、load capacitance 之間做折衷。

版本典型概念代價
X1較小、驅動能力較弱通常面積/功耗較低
X2較強 drive較大 area / power
X4更強 drive可驅動較大 load
X8非常強 drive通常更大、更耗電

例子：同一條邏輯

assign y = a & b;

若 load 很小：

AND2_X1 U1 (...);

若 load 較大或 timing 很緊：

AND2_X4 U1 (...);
Cell 不是「越大越好」，而是要剛好滿足 timing / load，同時控制 area 與 power。

6. Standard Cell 的 Physical Design 特性

Standard-cell design style 的重要特性是： 同一個 library 的 cells 通常有固定高度、不同寬度。 這樣才能像積木一樣排成 rows。

Fixed Height

同一 library cell 高度統一。

Variable Width

不同 cell 複雜度 / strength 寬度不同。

Power Rails

VDD / VSS 沿 cell row 對齊。

課程也指出 pin placement、obstruction layer 等 abstract physical 資訊會放在 LEF 中，供 P&R 使用。

7. 一顆 Standard Cell 為什麼要有很多種 Library View？

因為 synthesis、simulation、place-and-route、LVS、fabrication 各自需要不同資訊。 同一顆 cell 不能只靠一個檔案完成整個流程。

格式View主要內容使用階段

.lefAbstract PhysicalCell boundary、obstruction、pin locationsP&R

記憶法：.lib 給「時間與功耗」、LEF 給「抽象幾何」、GDS 給「完整版圖」、CDL/SPICE 給「電晶體電路」。

8. Cell Characterization 是什麼？

課程說明，Characterization 是對標準元件做大量 transistor-level SPICE simulation， 在不同條件下量測 cell 的 delay、slew rate、power 等特性。

為什麼不能只存一個 delay 數字？

因為 cell delay 會受到 input slew、output load、PVT 等因素影響， 所以通常需要 table/model，而不是一個固定常數。

Characterization 會跨不同 PVT corners 執行大量 SPICE simulations， 讓 STA / synthesis 可以在不同 operating conditions 下評估 timing 與 power。

11. 大量 Standard Cell 例子

例 1：Inverter

// RTL
assign y = ~a;

// mapped concept
INV_X1 U1 (.A(a), .ZN(y));

例 2：2-input NAND

assign y = ~(a & b);

// mapped concept
NAND2_X1 U1 (...);

例 3：2-input AND

assign y = a & b;

// possible cell
AND2_X1 U1 (...);

例 4：3-input AND

assign y = a & b & c;

// possible cell
AND3_X1 U1 (...);

例 5：4-input AND

assign y = a & b & c & d;

// possible cell
AND4_X1 U1 (...);

例 6：MUX2

assign y = sel ? b : a;

// possible mapped cell
MUX2_X1 U1 (...);

例 7：D Flip-Flop

always @(posedge clk)
    q <= d;

// possible mapped cell
DFF_X1 U_REG (...);

例 8：DFF with Set/Reset

always @(posedge clk or negedge rst_n)
    if (!rst_n)
        q <= 1'b0;
    else
        q <= d;

若 library 有對應 async-reset DFF，synthesis 可能直接選用該 cell。

例 9：Half Adder

assign sum   = a ^ b;
assign carry = a & b;

若 library 提供 HA cell，tool 可考慮使用；也可由 XOR + AND 組成。

例 10：Full Adder

assign sum  = a ^ b ^ cin;
assign cout = (a & b) | (a & cin) | (b & cin);

若 library 有 FA cell，mapping 可能選擇 FA；也可能拆成其他邏輯 cells，取決於 cost。

例 11：AOI 複合邏輯

assign y = ~((a & b) | (c & d));

若 library 提供 AOI cell，可能比多顆 AND + OR + INV 更有效率。

例 12：Buffer

assign y = a;

Logical function 雖然只是直通，但 physical flow 中可能插入 BUF 來改善 drive / fanout / timing。

例 13：Clock Buffer

Clock tree synthesis 常使用專用 CLKBUF，而不是隨便用一般 BUF， 因為 clock cells 通常針對 clock 特性設計與 characterize。

例 14：同一 cell 不同 strength

AND2_X1
AND2_X2
AND2_X4

功能完全一樣，但 drive、area、delay、power 特性不同。

例 15：同功能不同 implementation

assign y = ~(a & b);

可以直接用 NAND2，也可以 AND + INV；synthesis 會依 library 與目標選擇較合適的實作。

13. 常見誤解與考試重點

誤解 1：Standard Cell 只是 Verilog module

錯。它同時有 functional、timing/power、abstract physical、full layout、SPICE circuit 等多個 views。

誤解 2：X4 比 X1 功能更多

錯。通常 function 相同，只是 drive strength 不同。

誤解 3：Synthesis 只看 Boolean Function

錯。工具還會利用 library timing / area / power 資訊做 mapping 與 optimization。

誤解 4：.lef 就是完整 layout

錯。.lef 是 abstract geometry；完整 mask layout 是 GDS/GDSII。

誤解 5：Cell delay 是固定常數

錯。delay 會受 input slew、output load、PVT 等因素影響，課程也介紹 NLDM lookup table。

誤解 6：Standard Cell 越大越好

錯。更強 drive 通常伴隨更大的 area / power，需要折衷。

14. 自我測驗

Q1：Standard Cell Library 為什麼像 LEGO？

因為它由大量預先設計、驗證、characterize 的標準化 cells 組成，可以直接被 synthesis / physical design 重複使用。

Q2：AND2_X1 與 AND2_X4 有什麼差別？

功能相同，但 drive strength、area、timing、power 特性不同。

Q3：.lib / .db 主要提供什麼？

Timing 與 power model，例如 propagation delay、setup/hold、dynamic/leakage power。

Q4：.lef 與 .gds 差在哪？

LEF 是 P&R 用的 abstract geometry；GDS/GDSII 是完整 mask layout。

Q5：PVT 是什麼？

Process、Voltage、Temperature。

Q6：為什麼同一個 gate 要有 X1、X2、X4？

讓工具依 load 與 timing 需求選不同 drive strength，在 area/delay/power 間折衷。
