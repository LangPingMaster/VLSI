一、這份文件到底在教什麼？

這份附件是 《Workstation and SoC Lab Tutorial》，屬於 2026 Fall 的 VLSI System Design 課程環境操作教學。主要目的不是教 Verilog 本身，而是先教你：如何從 Windows 教室電腦連進實驗室 Linux Workstation、如何開啟圖形化 EDA 軟體、如何上傳下載檔案，以及如何修改密碼。

Windows 教室電腦
→
Xming
→
PuTTY / SSH
→
Linux Workstation
Windows 本機檔案
→
FileZilla / SFTP
→
Linux Workstation

Workstation 被教材定義為一台功能較強的電腦，並強調兩項重點：

  1. 運算能力較強。
  2. 可以同時支援多位使用者與多任務。

二、第 1～3 頁：Workstation 是什麼？

第 1 頁是封面。第 2 頁列出三個主題：

  • Introduction of workstation
  • Connect to the workstation
  • Change your password

第 3 頁開始解釋 workstation。教材寫：

Workstation = A powerful PC

並說明使用 workstation 的原因是：

  • Powerful computational ability
  • Support multi-user & multi-tasking

這裡最重要的不是「它是一台比較快的 PC」，而是理解：你的電腦只是操作端。

你的 Windows
    ↓
只是 Remote Client

Linux Workstation
    ↓
真正執行：
simulation
synthesis
EDA
CPU design
etc.

三、第 4～5 頁：Workstation 的 IP Address

在 EE building computer room

140.116.156.5
140.116.156.6

在 SoC computer room

192.168.200.5
192.168.200.6

這裡要特別理解一個觀念：為什麼兩邊 IP 不一樣？ 因為它們屬於不同網路環境。

EE Building
      │
      └── 140.116.156.x

SoC Lab internal network
      │
      └── 192.168.200.x
實際操作時，不要單純記「永遠連某一個 IP」，而是要先看自己目前所在的網路環境，再決定輸入哪一組位址。

四、第 6 頁：為什麼要開啟 Xming？

教材要求：

Before connecting to workstation, click Xming to run it in the background.

原因是：

Enabling the user to open the EDA tool with a graphical user interface (GUI).

PuTTY 本身主要給你文字終端機，例如：

ls
cd
pwd
vcs

但很多 EDA 軟體會開啟 waveform、schematic、layout、simulation GUI、synthesis GUI 等圖形視窗。這些視窗是 Linux 端產生的，但你坐在 Windows 電腦前，因此需要 Xming。

Linux GUI
→
X11 Protocol
→
SSH X11 Forwarding
→
Xming
→
Windows 顯示畫面

如果在 EE building：

你的 Windows
    ↓
encrypted SSH connection

六、第 8 頁：一定要打開 X11 Forwarding

PuTTY 裡要進入：

Connection
   ↓
SSH
   ↓
X11

然後勾選：

Enable X11 forwarding

Xming 與 X11 forwarding 是一組的：

狀況結果

只勾 X11 forwarding，沒開 XmingWindows 沒有 X Server 可以接收 GUI
Xming
  +
PuTTY X11 forwarding
  +
SSH

Make sure Xming is running.

此時就會開始 SSH connection。

八、第 10 頁：Host Key 是什麼？

第一次連伺服器時，PuTTY 通常會跳出 SSH Host Key 提示。教材要求出現這個視窗時接受它。

Host Key 的概念是：

用來確認你連線的是這台伺服器。

第一次連接時，你的電腦還沒有保存這台伺服器的身份資料，所以會詢問你是否信任這台主機。接受後，PuTTY 會記住伺服器的 key。

九、第 11～13 頁：登入 Workstation

第 11 頁：username

login as:

輸入學校／實驗室提供給你的 workstation username。

第 12 頁：password

student01@140.116.156.5's password:

輸入密碼。

Linux 的重要特點：輸入密碼時通常不會顯示任何字元，畫面上既不會顯示文字，也不一定會顯示星號，這是正常的。

十、第 13 頁：Login Successfully

登入成功後，就會進入 Linux shell。這表示你現在已經不是在 Windows 命令列，而是正在遠端操作 Linux workstation。

之後輸入的：

ls
cd
mkdir
vcs

都會在遠端伺服器上執行。

十一、這時你到底在哪裡？

你的實體位置
│
└── 成大 EE 電腦教室

你的 Windows 電腦
│
└── PuTTY

你的 Shell
│
└── Linux Workstation

你的工作目錄
│
└── /home/你的帳號/...

因此，如果你在 PuTTY 輸入：

rm test.v

刪除的是 workstation 上的 test.v，不是 Windows C:\... 裡的檔案。

十六、第 18 頁：連線成功

正常 FileZilla 畫面可以理解成左右兩邊：

Local                     Remote

        ↓ run simulation

        ↓ download

二十一、你在這份教材真正應該學會的 5 個觀念

  1. Local 與 Remote 不同
    Windows = Local；Linux workstation = Remote。
  2. PuTTY 是 SSH
    遠端登入與命令列操作。
  3. Xming 是 GUI 顯示端
    EDA GUI：Linux → Windows。
  4. FileZilla 是檔案傳輸
    Windows ↔ Linux。
  5. Linux 工作站才是後面 IC Design 真正執行工作的地方
    SystemVerilog、Simulation、Synthesis、EDA、CPU、ASIC flow 都會圍繞這個環境。
