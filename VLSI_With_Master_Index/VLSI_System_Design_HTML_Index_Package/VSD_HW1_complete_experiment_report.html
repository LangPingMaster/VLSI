3. Problem A — 32-bit ALU

ALU 主要輸入為 instruction_i、src_A_i、src_B_i，輸出為 result_o。運算種類由 RISC-V instruction 欄位解碼。

RV32IM

包含 ADD、SUB、SLL、SLT、SLTU、XOR、SRL、SRA、OR、AND、MUL、MULH、MULHSU、MULHU。

RV32B

包含 CLZ、CTZ、CPOP、ROL、ROR、MIN、MAX、MINU、MAXU、BSET、BCLR、BEXT。

Custom DSP

Instruction核心行為
DOTP4四組 signed 8-bit lane 相乘後累加。
SADD8四組 signed 8-bit lane 分別相加並做 ±128/127 saturation。
SSUB8四組 signed 8-bit lane 分別相減並做 saturation。
ABSsigned absolute value；0x80000000 特別飽和成 0x7FFFFFFF。
CLIP8將 signed 32-bit 輸入限制於 −128～127，輸出為 32-bit sign extension。
DSP lane 必須以 signed two's-complement 解讀，例如 8'hFF 是 −1，不是 255；SADD8/SSUB8 的 saturation 是每一個 8-bit lane 各自處理。

4. Problem B — IEEE-754 Single-Precision FPU

32-bit single precision 格式由 1-bit sign + 8-bit exponent + 23-bit fraction 組成。一般 normalized value 可理解為 (-1)^S × (1.F) × 2^(E-127)。

I/O

SignalWidth用途
clk / rst / enable1時脈、重置、輸入啟用

instruction20 MIN、1 MAX、2 ADD、3 SUB

valid1結果有效

ADD / SUB 資料路徑

Unpack S/E/F→Special Case→Exponent Align→Mantissa Add/Sub→Normalize→GRS Round→Pack

Unpack：先拆 sign、exponent、fraction，並辨認 NaN、Infinity、Zero。接著計算 ΔE = |Ea − Eb|，將 exponent 較小的 mantissa 右移，使兩數 exponent 對齊，再依 operand sign 與 ADD/SUB 指令決定 mantissa 加減。

Normalize：若加法產生 carry，mantissa 右移且 exponent +1；若 subtraction cancellation 產生 leading zero，則左移 mantissa 並降低 exponent。

GRS 與 Round-to-even

對齊或 normalization 造成右移時保留 Guard、Round、Sticky bits。GRS 用於 round-to-even：大於半個 ULP 時進位；剛好 tie 時依保留結果的 LSB 決定是否進位，使最後結果落在偶數。

作業規格另指定特殊情況，例如 NaN operand 產生 NaN；Infinity 的符號衝突情況需產生 NaN；Zero 與 Infinity 也需依講義規則處理。
