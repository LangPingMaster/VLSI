03｜RV32IM：14 個 ALU 指令

完整整理 HW1 指定的 ADD、SUB、SLL、SLT、SLTU、XOR、SRL、SRA、OR、AND、MUL、MULH、MULHSU、MULHU，以及實作時會遇到的相關專有名詞。每個條目至少 2 個例子。
本頁資料基準：14 條 instruction 的 funct7、funct3、opcode 與 operation formula 依 HW1 PDF 的 RV32IM Instructions table 整理。延伸名詞只用來幫助理解，不取代老師的作業規格。

14 條指令先分成 5 類

Arithmetic
ADD / SUB→Shift
SLL / SRL / SRA→Compare
SLT / SLTU→Logic
XOR / OR / AND→Multiply
MUL / MULH / MULHSU / MULHU

01ADD加法⌄
RV32IM ALU 指令Addition

HW1 規格

PDF RV32IM Instructions table：funct7=0000000、funct3=000、opcode=0110011；operation：rd = rs1 + rs2。

詳細說明

將 rs1 與 rs2 的 32-bit 值相加，輸出到 rd。PDF 在 RV32IM 表中直接以 `rd = rs1 + rs2` 定義。

例子（至少 2 個）

例 1

rs1=5、rs2=3 → rd=8。

例 2

rs1=100、rs2=25 → rd=125。

02SUB減法⌄
RV32IM ALU 指令Subtraction

HW1 規格

PDF RV32IM Instructions table：funct7=0100000、funct3=000、opcode=0110011；operation：rd = rs1 - rs2。

詳細說明

以 rs1 為被減數、rs2 為減數。它與 ADD 的 funct3 都是 000，因此 decode 時必須利用 funct7 區分。

例子（至少 2 個）

例 1

rs1=10、rs2=3 → rd=7。

例 2

rs1=3、rs2=10 → 32-bit two's-complement 結果代表 -7。

03SLL邏輯左移⌄
RV32IM ALU 指令Shift Left Logical

HW1 規格

PDF RV32IM Instructions table：funct7=0000000、funct3=001、opcode=0110011；operation：rd = rs1 << rs2[4:0]。

詳細說明

將 rs1 向左移動，shift amount 只取 rs2[4:0]。左側移出的 bits 被丟棄，右側補 0。

例子（至少 2 個）

例 1

rs1=1、rs2[4:0]=3 → 1<<3=8。

例 2

rs1=0x0000000F、shift=4 → rd=0x000000F0。

04SLT有號小於比較⌄
RV32IM ALU 指令Set Less Than

HW1 規格

PDF RV32IM Instructions table：funct7=0000000、funct3=010、opcode=0110011；operation：rd = (rs1 < rs2) ? 1 : 0 (signed)。

詳細說明

把兩個 operands 當 signed values 比較；若 rs1 小於 rs2，rd=1，否則 rd=0。

例子（至少 2 個）

例 1

rs1=-5、rs2=2，以 signed 比較 → rd=1。

例 2

rs1=7、rs2=3 → rd=0。

05SLTU無號小於比較⌄
RV32IM ALU 指令Set Less Than Unsigned

HW1 規格

PDF RV32IM Instructions table：funct7=0000000、funct3=011、opcode=0110011；operation：rd = (rs1 < rs2) ? 1 : 0 (unsigned)。

詳細說明

與 SLT 的差異在 interpretation：SLTU 將相同 32-bit patterns 視為 unsigned。

例子（至少 2 個）

例 1

rs1=3、rs2=10 → rd=1。

例 2

rs1=0xFFFFFFFF、rs2=1；unsigned 下前者很大，因此 rd=0。

06XOR互斥或⌄
RV32IM ALU 指令Exclusive OR

HW1 規格

PDF RV32IM Instructions table：funct7=0000000、funct3=100、opcode=0110011；operation：rd = rs1 ^ rs2。

詳細說明

逐 bit 執行 XOR：兩個 input bits 不同時輸出 1，相同時輸出 0。

例子（至少 2 個）

例 1

0b1010 XOR 0b1100 = 0b0110。

例 2

0xFFFFFFFF XOR 0xFFFFFFFF = 0x00000000。

07SRL邏輯右移⌄
RV32IM ALU 指令Shift Right Logical

HW1 規格

PDF RV32IM Instructions table：funct7=0000000、funct3=101、opcode=0110011；operation：rd = rs1 >> rs2[4:0] (logical)。

詳細說明

將 rs1 邏輯右移，shift amount 取 rs2[4:0]；高位補 0。

例子（至少 2 個）

例 1

0x00000010 >> 2 = 0x00000004。

例 2

0x80000000 logical >> 1 = 0x40000000。

08SRA算術右移⌄
RV32IM ALU 指令Shift Right Arithmetic

HW1 規格

PDF RV32IM Instructions table：funct7=0100000、funct3=101、opcode=0110011；operation：rd = rs1 >>> rs2[4:0] (arithmetic)。

詳細說明

算術右移用來保留 signed number 的符號意義；PDF 以 `>>>` 表示 arithmetic shift。

例子（至少 2 個）

例 1

正數 8 arithmetic >> 1 → 4。

例 2

0x80000000 arithmetic >> 1 → 高位以符號位延伸，得到 0xC0000000。

09OR逐位元 OR⌄
RV32IM ALU 指令Bitwise OR

HW1 規格

PDF RV32IM Instructions table：funct7=0000000、funct3=110、opcode=0110011；operation：rd = rs1 | rs2。

詳細說明

逐 bit OR，只要對應的任一 bit 為 1，result bit 就為 1。

例子（至少 2 個）

例 1

0b1010 OR 0b1100 = 0b1110。

例 2

0x0000FF00 OR 0x000000FF = 0x0000FFFF。

10AND逐位元 AND⌄
RV32IM ALU 指令Bitwise AND

HW1 規格

PDF RV32IM Instructions table：funct7=0000000、funct3=111、opcode=0110011；operation：rd = rs1 & rs2。

詳細說明

逐 bit AND，只有兩個對應 bits 都為 1 時 result bit 才為 1。

例子（至少 2 個）

例 1

0b1010 AND 0b1100 = 0b1000。

例 2

0xFFFF0000 AND 0x00FF00FF = 0x00FF0000。

11MUL乘法低 32 bits⌄
RV32IM ALU 指令Multiply, low part

HW1 規格

PDF RV32IM Instructions table：funct7=0000001、funct3=000、opcode=0110011；operation：rd = (rs1 * rs2)[31:0]。

詳細說明

PDF 指定取得乘積的低 32 bits。對 MUL 這個作業定義，核心是產生乘積後選取 [31:0]。

例子（至少 2 個）

例 1

3×4=12 → 低 32 bits 為 0x0000000C。

例 2

0x00010000×0x00010000=0x0000000100000000 → rd 取低 32 bits=0。

12MULH有號×有號乘法高 32 bits⌄
RV32IM ALU 指令Multiply High Signed × Signed

HW1 規格

PDF RV32IM Instructions table：funct7=0000001、funct3=001、opcode=0110011；operation：rd = (signed(rs1) * signed(rs2))[63:32]。

詳細說明

兩個 operands 都依 signed 解讀，形成較寬乘積，再取 [63:32]。與 MUL 最大差異是它取 high half。

例子（至少 2 個）

例 1

小正數 2×3 的 64-bit product 高 32 bits 為 0。

例 2

rs1=-1、rs2=2 → signed product=-2；64-bit two's-complement 的高 32 bits 為 0xFFFFFFFF。

13MULHSU有號×無號乘法高 32 bits⌄
RV32IM ALU 指令Multiply High Signed × Unsigned

HW1 規格

PDF RV32IM Instructions table：funct7=0000001、funct3=010、opcode=0110011；operation：rd = (signed(rs1) * unsigned(rs2))[63:32]。

詳細說明

第一 operand 依 signed 解讀，第二 operand 依 unsigned 解讀，再取乘積高 32 bits。這個 mixed signedness 是最容易實作錯誤的地方之一。

例子（至少 2 個）

例 1

rs1=2、rs2=3 時兩者皆為正，product=6，高 32 bits=0。

例 2

rs1=0xFFFFFFFF 代表 signed -1；rs2=2 為 unsigned 2，因此 product=-2，再取高 32 bits。

14MULHU無號×無號乘法高 32 bits⌄
RV32IM ALU 指令Multiply High Unsigned × Unsigned

HW1 規格

PDF RV32IM Instructions table：funct7=0000001、funct3=011、opcode=0110011；operation：rd = (unsigned(rs1) * unsigned(rs2))[63:32]。

詳細說明

兩個 operands 都視為 unsigned，產生乘積後取 [63:32]。

例子（至少 2 個）

例 1

2×3=6，高 32 bits=0。

例 2

0xFFFFFFFF×0xFFFFFFFF = 0xFFFFFFFE00000001，因此高 32 bits=0xFFFFFFFE。

15RV32IM本作業的 RV32IM 指令集合⌄
相關專有名詞RV32IM instructions used by HW1

HW1 規格

以 PDF RV32IM operation descriptions 為主要依據；若屬表示法背景，說明中會明確指出。

詳細說明

PDF 的 RV32IM table 共列 14 instructions，並指定共同 opcode=0110011。這 14 條包含 arithmetic、shift、comparison、logical 與 multiply 類。

例子（至少 2 個）

例 1

ADD～AND 是基本算術、比較、shift 與 bitwise operations。

例 2

MUL、MULH、MULHSU、MULHU 是四個 multiply operations。

16Signed有號解讀⌄
相關專有名詞Signed interpretation

HW1 規格

以 PDF RV32IM operation descriptions 為主要依據；若屬表示法背景，說明中會明確指出。

詳細說明

Signed 表示 bit pattern 需要依有號二進位數解讀。本 PDF 明確在 SLT、MULH、MULHSU 等 operation 中標示 signed。

例子（至少 2 個）

例 1

0xFFFFFFFF 作為 32-bit signed 可表示 -1。

例 2

SLT 比較 -1 與 1 時，signed(-1)<signed(1)，因此結果為 1。

17Unsigned無號解讀⌄
相關專有名詞Unsigned interpretation

HW1 規格

以 PDF RV32IM operation descriptions 為主要依據；若屬表示法背景，說明中會明確指出。

詳細說明

Unsigned 將全部 bits 用來表示非負整數。PDF 的 SLTU、MULHSU 第二 operand、MULHU 都明確涉及 unsigned。

例子（至少 2 個）

例 1

0xFFFFFFFF 作為 32-bit unsigned 是很大的正整數，而不是 -1。

例 2

SLTU 比較 0xFFFFFFFF 與 1 時，前者較大，因此結果為 0。

18Logical Shift邏輯位移⌄
相關專有名詞Logical Shift

HW1 規格

以 PDF RV32IM operation descriptions 為主要依據；若屬表示法背景，說明中會明確指出。

詳細說明

PDF 的 SLL 與 SRL 屬 logical shift；SRL 特別標示 `(logical)`。右移時的高位補 0。

例子（至少 2 個）

例 1

SRL：0x80000000 >> 1 → 0x40000000。

例 2

SLL：0x1 << 4 → 0x10。

19Arithmetic Shift算術位移⌄
相關專有名詞Arithmetic Shift

HW1 規格

以 PDF RV32IM operation descriptions 為主要依據；若屬表示法背景，說明中會明確指出。

詳細說明

PDF 的 SRA 明確標示 `(arithmetic)` 並使用 `>>>`。它與 SRL 的重要差異是對 signed value 的右移語意。

例子（至少 2 個）

例 1

SRA 對正數 8 右移 1 → 4。

例 2

SRA 對最高 bit=1 的負值右移時會維持符號延伸；SRL 則高位補 0。

20Shift Amount位移量⌄
相關專有名詞rs2[4:0]

HW1 規格

以 PDF RV32IM operation descriptions 為主要依據；若屬表示法背景，說明中會明確指出。

詳細說明

PDF 的 SLL、SRL、SRA 都只取 rs2[4:0] 作為 shift amount。

例子（至少 2 個）

例 1

rs2=3 → rs2[4:0]=3，所以 shift 3 bits。

例 2

rs2=32 (0b100000) 時，低 5 bits 為 00000，因此依這個作業公式 shift amount 為 0。

21Bitwise Operation逐位元運算⌄
相關專有名詞Bitwise operation

HW1 規格

以 PDF RV32IM operation descriptions 為主要依據；若屬表示法背景，說明中會明確指出。

詳細說明

XOR、OR、AND 的 PDF formulas 分別使用 ^、|、&，代表每一個 bit position 獨立運算。

例子（至少 2 個）

例 1

AND 可用 mask 保留指定為 1 的 bit positions。

例 2

XOR 相同 bits 得 0、不同 bits 得 1，因此 1010 XOR 1100 = 0110。

22High 32 bits乘積高 32 bits⌄
相關專有名詞Product [63:32]

HW1 規格

以 PDF RV32IM operation descriptions 為主要依據；若屬表示法背景，說明中會明確指出。

詳細說明

PDF 的 MULH、MULHSU、MULHU 都取乘積 [63:32]。

例子（至少 2 個）

例 1

若 64-bit product=0x12345678ABCDEF00，高 32 bits 是 0x12345678。

例 2

MULHU 的 0xFFFFFFFF×0xFFFFFFFF product 高半部為 0xFFFFFFFE。

23Low 32 bits乘積低 32 bits⌄
相關專有名詞Product [31:0]

HW1 規格

以 PDF RV32IM operation descriptions 為主要依據；若屬表示法背景，說明中會明確指出。

詳細說明

PDF 的 MUL 定義為 `(rs1 * rs2)[31:0]`。

例子（至少 2 個）

例 1

product=0x000000000000000C → low 32=0x0000000C。

例 2

product=0x0000000100000000 → low 32=0x00000000。

24Comparison比較運算⌄
相關專有名詞Comparison operation

HW1 規格

以 PDF RV32IM operation descriptions 為主要依據；若屬表示法背景，說明中會明確指出。

詳細說明

PDF 的 SLT/SLTU 會比較兩個 operands 並把 rd 設成 1 或 0；差別是 signedness。

例子（至少 2 個）

例 1

SLT：-1 < 1 → 1。

例 2

SLTU：0xFFFFFFFF < 1 為 false → 0。

25Two's Complement二補數表示法⌄
相關專有名詞Two's-complement representation

HW1 規格

以 PDF RV32IM operation descriptions 為主要依據；若屬表示法背景，說明中會明確指出。

詳細說明

PDF 在 DSP notes 明確提到 signed two's-complement；在 RV32IM signed operations 中，理解 two's-complement 也有助於判讀 signed bit patterns。本項後半屬背景解釋。

例子（至少 2 個）

例 1

32-bit 0xFFFFFFFF 可解讀為 signed -1。

例 2

32-bit 0x80000000 在 two's-complement signed 解讀下是最小負值。
