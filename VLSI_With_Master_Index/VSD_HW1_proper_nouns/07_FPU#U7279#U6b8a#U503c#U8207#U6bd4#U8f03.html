07｜FPU 特殊值與比較

以 VSD HW1 FPU 規格為核心，整理 NaN、±Infinity、±Zero、Special Case、FPU Comparator、MIN/MAX、MUX，以及相關介面與 corner cases。每個名詞至少 2 個例子。
重要：ADD/SUB 的 NaN、Inf、Zero special-case 規則在 PDF 有明確表格；但 PDF 並沒有提供 MIN/MAX 對 NaN、±0 等情況的完整特殊比較規則。因此本頁不自行把一般 IEEE-754 規則冒充成 HW1 規格，MIN/MAX 的 hidden-test 精確行為應以老師提供的 testbench / pattern 為準。

01FPU浮點運算單元⌄
核心硬體名詞Floating-Point Unit

HW1 PDF 中的依據

HW1 的 FPU 為 32-bit IEEE-754 single-precision FPU，支援 ADD、SUB、MIN、MAX，並有特殊值處理。

詳細說明

FPU 是專門處理浮點資料的運算單元。本章聚焦於一般算術之前的特殊值判定，以及 MIN/MAX 比較路徑。

例子（至少 2 個）

例 1

instruction=0 時，PDF I/O table 指定執行 MIN。

例 2

instruction=2 時執行 ADD；若 operand 是 NaN/Inf/Zero，需先進行 special-case handling。

詳細說明

特殊值不是直接套用一般 normalized mantissa arithmetic。硬體通常先看 exponent 與 fraction pattern，再選擇特殊處理路徑。

03Special Case特殊情況處理⌄

詳細說明

Special-case handling 的目的，是在進入 exponent alignment、mantissa add/sub 之前，先處理 NaN、Infinity、Zero 等規格指定情況。

例 1

04NaN非數值⌄
IEEE-754 特殊值Not a Number

HW1 PDF 中的依據

PDF：Exponent=255 且 Fraction≠0 時判定 NaN；ADD/SUB special-case table 指定 NaN result pattern 為 32'hFFC00000。

詳細說明

NaN 表示不能當作一般有限浮點數處理的特殊資料。本頁只採 HW1 PDF 明確給出的 detection 與 ADD/SUB output 規則，不額外假設 MIN/MAX 的 NaN semantics。

例子（至少 2 個）

例 1

E=255、F=1 → 符合 PDF 的 NaN detection。

例 2

ADD/SUB 中只要任一 operand 為 NaN，PDF 指定 result=0xFFC00000。

05Infinity / Inf無窮大⌄
IEEE-754 特殊值Infinity

HW1 PDF 中的依據

PDF：Exponent=255 且 Fraction=0 時判定 Inf。

詳細說明

Infinity 仍保留 sign，因此可分成 +Inf 與 -Inf。HW1 ADD/SUB table 對 infinity 提供特別處理，而不是把它當一般 1.F mantissa 計算。

例子（至少 2 個）

例 1

S=0、E=255、F=0 → +Inf。

例 2

S=1、E=255、F=0 → -Inf。

詳細說明

Zero 的 exponent 與 fraction 都是 0，但 sign 可以是 0 或 1，因此存在 +0 與 -0。

15MIN浮點最小值⌄
FPU 比較操作Floating-Point Minimum

HW1 PDF 中的依據

詳細說明

MIN 的基本目的為在兩個浮點 operands 中選擇較小者；然而 PDF 未明列 NaN、+0/-0 等特殊比較 semantics，所以 hidden-test 的精確行為需以提供的 testbench/pattern 為準。

例子（至少 2 個）

例 2

例 2
