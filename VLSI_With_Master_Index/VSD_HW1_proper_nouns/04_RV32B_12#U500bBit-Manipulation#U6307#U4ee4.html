04｜RV32B：12 個 Bit-Manipulation 指令

依 VSD HW1 的 RV32B table 整理 12 條指令，並補充 Bit Manipulation、Leading/Trailing Zero、Population Count、Rotate、Signed/Unsigned Comparison、Bit Index、Mask、MSB/LSB 等專有名詞。每個條目至少提供 2 個例子。
資料基準：12 條 RV32B 指令的 funct7、[24:20]、funct3、opcode 與 operation 依 HW1 PDF 整理。額外加入的 Mask、MSB、LSB 等名詞是為了幫助理解；若不是 PDF 的正式定義，頁面會明確標示。

快速圖解｜CLZ、CTZ、CPOP 的差異

01CLZ計算前導 0 數量⌄
RV32B 指令Count Leading Zeros

HW1 規格／依據

RV32B table：funct7=0110000、[24:20]=00000、funct3=001、opcode=0010011；operation：rd = count_leading_zeros(rs1)。

詳細說明

從 rs1 的最高有效位 MSB 方向開始，計算連續出現多少個 0，直到遇到第一個 1。這條指令只需要 rs1；PDF 因此把 [24:20] 固定編碼為 00000。

例子（至少 2 個）

例 1｜一般值

rs1=0x00F00000。最高 8 bits 為 00000000，下一個 nibble 的第一個 bit 已是 1，因此 CLZ=8。

例 2｜最高位為 1

rs1=0x80000000，bit31 已經是 1，所以前面沒有任何 leading zero，rd=0。

例 3｜全零

若 rs1=0x00000000，32 個 bits 全為 0，因此對 32-bit operand，leading-zero count 為 32。

02CTZ計算尾端 0 數量⌄
RV32B 指令Count Trailing Zeros

HW1 規格／依據

RV32B table：funct7=0110000、[24:20]=00001、funct3=001、opcode=0010011；operation：rd = count_trailing_zeros(rs1)。

詳細說明

從 rs1 的最低有效位 LSB 方向開始，計算連續 0 的數量，直到遇到第一個 1。CLZ、CTZ、CPOP 的 funct7/funct3/opcode 相同，PDF 用 [24:20] 的固定值區分。

例子（至少 2 個）

例 1

rs1=0x00000008 = ...1000，最低端有 3 個連續 0，所以 CTZ=3。

例 2

rs1=0x00000001，bit0 已為 1，所以 CTZ=0。

例 3

rs1=0x00000100，唯一的 1 在 bit8，因此 trailing zeros=8。

03CPOP計算 1 的個數⌄
RV32B 指令Count Population

HW1 規格／依據

RV32B table：funct7=0110000、[24:20]=00010、funct3=001、opcode=0010011；operation：rd = count_ones(rs1)。

詳細說明

計算 rs1 的 32 bits 中共有多少個 1，常稱 population count。PDF 用 [24:20]=00010 與 CLZ/CTZ 區分。

例子（至少 2 個）

例 1

rs1=0x0000000F，低 4 bits 都是 1，所以 CPOP=4。

例 2

rs1=0xFFFFFFFF，32 bits 全為 1，所以 CPOP=32。

例 3

rs1=0x00000000，沒有任何 1，所以 CPOP=0。

04ROL循環左移⌄
RV32B 指令Rotate Left

HW1 規格／依據

RV32B table：funct7=0110000、[24:20]=rs2、funct3=001、opcode=0110011；operation：rd = rotate_left(rs1, rs2[4:0])。

詳細說明

將 rs1 循環向左旋轉。與普通 SLL 不同，被左側移出去的 bits 不會消失，而是繞回右側。PDF 指定旋轉量由 rs2[4:0] 決定。

例子（至少 2 個）

例 1

以 8-bit 示意：10000001 左旋 1 bit → 00000011；最左邊的 1 繞回最低位。

例 2

32-bit rs1=0x80000001 左旋 1 bit → 0x00000003。

例 3

若 rs2[4:0]=0，旋轉 0 bit，result 與 rs1 相同。

05ROR循環右移⌄
RV32B 指令Rotate Right

HW1 規格／依據

RV32B table：funct7=0110000、[24:20]=rs2、funct3=101、opcode=0110011；operation：rd = rotate_right(rs1, rs2[4:0])。

詳細說明

將 rs1 循環向右旋轉。從最低位移出去的 bits 會回到最高位，因此不同於 SRL 的高位補 0。

例子（至少 2 個）

例 1

以 8-bit 示意：10000001 右旋 1 bit → 11000000。

例 2

32-bit rs1=0x00000001 右旋 1 bit → 0x80000000。

例 3

rs1=0x12345678、rotation amount=0 → result 仍為 0x12345678。

06MIN有號最小值⌄
RV32B 指令Minimum Signed

HW1 規格／依據

RV32B table：funct7=0000101、[24:20]=rs2、funct3=100、opcode=0110011；operation：rd = min(signed(rs1), signed(rs2))。

詳細說明

把 rs1、rs2 當作 signed 32-bit values，比較後輸出較小者。重點是 signed interpretation。

例子（至少 2 個）

例 1

rs1=5、rs2=9 → MIN=5。

例 2

rs1=0xFFFFFFFF（signed -1）、rs2=1 → MIN=0xFFFFFFFF，也就是 -1。

例 3

rs1=-100、rs2=-3 → 較小的是 -100。

07MAX有號最大值⌄
RV32B 指令Maximum Signed

HW1 規格／依據

RV32B table：funct7=0000101、[24:20]=rs2、funct3=110、opcode=0110011；operation：rd = max(signed(rs1), signed(rs2))。

詳細說明

把兩個 operands 當 signed values，輸出較大者。它與 MIN 使用相同 funct7/opcode，但 funct3 不同。

例子（至少 2 個）

例 1

rs1=5、rs2=9 → MAX=9。

例 2

rs1=0xFFFFFFFF（-1）、rs2=1 → MAX=1。

例 3

rs1=-100、rs2=-3 → MAX=-3。

08MINU無號最小值⌄
RV32B 指令Minimum Unsigned

HW1 規格／依據

RV32B table：funct7=0000101、[24:20]=rs2、funct3=101、opcode=0110011；operation：rd = min(unsigned(rs1), unsigned(rs2))。

詳細說明

將 rs1、rs2 視為 unsigned 32-bit values，輸出較小者。相同 bit pattern 在 MIN 與 MINU 中可能產生不同結果。

例子（至少 2 個）

例 1

rs1=5、rs2=9 → MINU=5。

例 2

rs1=0xFFFFFFFF、rs2=1。unsigned 下 0xFFFFFFFF 很大，所以 MINU=1。

例 3

rs1=0x80000000、rs2=0x7FFFFFFF，unsigned 下後者較小，因此輸出 0x7FFFFFFF。

09MAXU無號最大值⌄
RV32B 指令Maximum Unsigned

HW1 規格／依據

RV32B table：funct7=0000101、[24:20]=rs2、funct3=111、opcode=0110011；operation：rd = max(unsigned(rs1), unsigned(rs2))。

詳細說明

將兩個 operands 視為 unsigned，輸出較大者。這與 MAX 的 signed comparison 形成對照。

例子（至少 2 個）

例 1

rs1=5、rs2=9 → MAXU=9。

例 2

rs1=0xFFFFFFFF、rs2=1 → MAXU=0xFFFFFFFF。

例 3

rs1=0x80000000、rs2=0x7FFFFFFF → unsigned 下 0x80000000 較大。

10BSET設定指定位元⌄
RV32B 指令Bit Set

HW1 規格／依據

RV32B table：funct7=0010100、[24:20]=rs2、funct3=001、opcode=0110011；operation：rd = rs1 | (1 << rs2[4:0])。

詳細說明

把 rs2[4:0] 當作 bit index，將 rs1 對應位置設定成 1，其餘 bits 保持原狀。

例子（至少 2 個）

例 1

rs1=0、rs2[4:0]=3 → mask=0x8，BSET 後 rd=0x00000008。

例 2

rs1=0x00000008、index=3；bit3 本來已是 1，所以 result 仍是 0x00000008。

例 3

index=31 時，會設定最高位 bit31。

11BCLR清除指定位元⌄
RV32B 指令Bit Clear

HW1 規格／依據

RV32B table：funct7=0100100、[24:20]=rs2、funct3=001、opcode=0110011；operation：rd = rs1 & ~(1 << rs2[4:0])。

詳細說明

把 rs2[4:0] 指定的 bit 清成 0，其餘 bits 不變。概念上先產生 one-hot mask，再反相後與 rs1 做 AND。

例子（至少 2 個）

例 1

rs1=0x0000000F、index=2 → 清掉 bit2，result=0x0000000B。

例 2

rs1=0xFFFFFFFF、index=0 → result=0xFFFFFFFE。

例 3

若指定 bit 原本就是 0，BCLR 後數值不變。

12BEXT抽取指定位元⌄
RV32B 指令Bit Extract

HW1 規格／依據

RV32B table：funct7=0100100、[24:20]=rs2、funct3=101、opcode=0110011；operation：rd = (rs1 >> rs2[4:0]) & 1。

詳細說明

利用 rs2[4:0] 選定 rs1 的某一個 bit，並把該 bit 抽出成 result。輸出語意為 0 或 1。

例子（至少 2 個）

例 1

rs1=0b1000、index=3 → 抽到 1，所以 rd=1。

例 2

rs1=0b1000、index=2 → bit2=0，所以 rd=0。

例 3

rs1=0x80000000、index=31 → 抽取最高位，rd=1。
