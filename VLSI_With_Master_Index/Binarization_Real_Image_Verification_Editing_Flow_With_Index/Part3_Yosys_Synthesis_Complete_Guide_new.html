5. RTL：design.sv

`timescale 1ns/1ps
module binarization (
    input  wire       clk,
    input  wire       rst_n,
    input  wire [7:0] pix_in,
    input  wire [7:0] threshold,
    output reg        pix_out
);
always @(posedge clk or negedge rst_n) begin
    if (!rst_n)
        pix_out <= 1'b0;
    else if (pix_in >= threshold)
        pix_out <= 1'b1;
    else
        pix_out <= 1'b0;
end
endmodule

功能：每個 clock 正緣判斷 pix_in >= threshold。本次 image verification 的 threshold 固定為 128。

7. Yosys 產出內容

7.1 查看 Verilog netlist

Get-Content .\binarization_yosys.v

本次輸出的 binarization_yosys.v 是 simulation-friendly Verilog。組合邏輯已被展開成大量 assign，例如：

assign _01_ = ~pix_in[0];
assign _09_ = ~(_03_ & threshold[7]);
assign _19_ = pix_in[1] | _05_;
...
assign _00_ = _09_ & _39_;

而原本的 registered output 仍以 sequential always block 表示：

always @(posedge clk, negedge rst_n)
  if (!rst_n) pix_out <= 1'h0;
  else pix_out <= _00_;
這表示本次 binarization_yosys.v 不需要額外加入 simcells.v，可直接交給 Icarus Verilog 模擬。

7.2 JSON 的意義

binarization_yosys.json 保留了 Yosys 對此設計的 module、port、cell 與 net 結構。內部可看到 $_NOT_、$_NAND_、$_AND_、$_OR_ 與 DFF 等 synthesis cell 表示。

8. testbench_yosys.sv：Actual Netlist Testbench

`timescale 1ns/1ps

module tb_binarization_yosys;

localparam N = 65536;

reg clk;
reg rst_n;
reg [7:0] pix_in;
reg [7:0] threshold;
wire pix_out;

reg [7:0] img_mem [0:N-1];

integer i;
integer fout;

binarization dut (
    .clk(clk),
    .rst_n(rst_n),
    .pix_in(pix_in),
    .threshold(threshold),
    .pix_out(pix_out)
);

initial clk = 0;
always #5 clk = ~clk;

initial begin
    $readmemh("gray.hex", img_mem);

    fout = $fopen("yosys_binary.txt", "w");

    threshold = 8'd128;
    rst_n = 0;
    pix_in = 0;

    #12;
    rst_n = 1;

    for (i = 0; i < N; i = i + 1) begin
        @(negedge clk);
        pix_in = img_mem[i];

        @(posedge clk);
        #1;

        $fwrite(fout, "%0d\n", pix_out);
    end

    $fclose(fout);

    $display("Yosys Netlist: Processed %0d pixels. Done.", N);

    #10;
    $finish;
end

endmodule

時序：每個 pixel 在 negedge clk 放入，下一個 posedge clk 後等待 #1 再讀取 registered pix_out，確保取到更新後的輸出。

10. Python Golden Model 比對

10.1 compare_yosys.py

from PIL import Image
import numpy as np

golden = np.loadtxt("../data/golden_binary.txt", dtype=np.uint8)
yosys = np.loadtxt("yosys_binary.txt", dtype=np.uint8)

if yosys.size != golden.size:
    raise SystemExit(
        f"size mismatch: Yosys={yosys.size}, Golden={golden.size}"
    )

mismatch = int(np.count_nonzero(yosys != golden))
accuracy = (1 - mismatch / golden.size) * 100

img = (yosys.reshape(256, 256) * 255).astype(np.uint8)
Image.fromarray(img, mode="L").save("../images/sample_binary_yosys.png")

print("Total pixels:", golden.size)
print("Mismatch pixels:", mismatch)
print("Accuracy: %.2f%%" % accuracy)

if mismatch == 0:
    print("PASS")
else:
    print("FAIL")

12. 實際遇到的問題與修正

問題原因修正
cd D:\oss-cad-suite 找不到路徑 實際 OSS CAD Suite 並不在 D:\ 根目錄。 使用真正路徑：
D:\userdata\Downloads\oss-cad-suite-windows-x64-20260914\oss-cad-suite
一開始下載 darwin-arm64 這是 macOS ARM64 版本。 改下載 windows-x64。
environment.ps1 未經數位簽署 PowerShell Execution Policy 阻擋。 Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
yosys 無法辨識 PowerShell 尚未載入 OSS CAD Suite 環境。 . .\environment.ps1，或暫時加入 $PWD\bin 到 PATH。
testbench_yosys.sv:1: syntax error testbench 第一行誤留 PowerShell here-string 的 @'。 刪除檔案開頭的 @'，並確認檔尾沒有 '@。檔案第一行應直接是 `timescale 1ns/1ps。
compare_yosys.py: No such file or directory 新 comparison script 尚未建立。 建立 compare_yosys.py 後再執行。
