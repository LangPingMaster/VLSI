00-4｜ALU：從 Decode 到 31 個 Operations 的 Datapath 思維

本頁以 VSD HW1 的 ALU 規格為核心：輸入 instruction_i、src_A_i、src_B_i，輸出 result_o。作業要求可分為 RV32IM 14 個、RV32B 12 個、Custom DSP 5 個，共 31 個 operations。重點是理解 signedness、width、bit manipulation 與 saturation。

一、ALU 完整運作流程圖

instruction_i→Decode→Operation Select→Arithmetic / Compare / Shift / Multiply / Bitmanip / DSP→MUX→result_o

三、SLT / SLTU / MIN / MAX

A = 32'hFFFF_FFFF
B = 32'h0000_0001

signed   : A=-1          → A<B → SLT=1
unsigned : A=4294967295  → A>B → SLTU=0
OpInterpretation結果
SLTsignedA<B ? 1:0
SLTUunsignedA<B ? 1:0
MIN/MAXsigned回傳較小/大 operand
MINU/MAXUunsigned回傳較小/大 operand

四、SLL / SRL / SRA / ROL / ROR

shamt = src_B_i[4:0]　→　0～31
Op動作
SLL左移，右側補 0
SRL右移，左側補 0
SRA右移，左側複製 sign bit
ROL左側移出的 bits 繞回右側
ROR右側移出的 bits 繞回左側
8'b1111_0000
SRL 2 → 0011_1100
SRA 2 → 1111_1100

測試時特別檢查 shamt=0、1、31。

五、MUL / MULH / MULHSU / MULHU

32-bit A×32-bit B→完整 64-bit product→Low / High Word
OpABOutput
MUL——low 32
MULHsignedsignedhigh 32
MULHSUsignedunsignedhigh 32
MULHUunsignedunsignedhigh 32

MULHSU 最容易因 expression width/signedness 寫錯；應明確擴展 operands、保留完整 intermediate，再取 high word。

38 {7'b0000000,3'b110}: result_o = src_A_i | src_B_i;OR：逐 bit OR。

完成本章後應能回答

SLT/SLTU：signed/unsigned interpretation 不同。　SRL/SRA：補 0 與補 sign bit 不同。　MULH：需要完整寬度 product 的 high word。　SADD8：四個 lane 各有自己的 [-128,127] 飽和邊界。
